## 背景

task073/task074 的 robot_wam 训练显示 `eval_mean_loss` 几乎完全由
未归一化 action MSE 主导，且训练内 `max_eval_samples=512` 直接取 split 文件前
512 条，导致 OOD eval 实际只覆盖 `grab_cube2_v1` 的前部样本，不能代表固定 OOD
集合。用户要求本轮修复：

1. action 归一化。
2. eval 口径修正，确保固定 eval 集合被正确使用。
3. 参考 DreamZero action 处理方式，核对是否应让 backbone 参与 action token 去噪。

当前 `robot_wam` 实现仍在 `.worktrees/t070` 且尚未合并到 main，其中
`src/pipeline/robot_wam.py`、`robot_wam_wan.py` 和 `robot_wam_model_fn.py`
仍是 t070 worktree 的未跟踪实现文件。因此本任务作为 task070 的 follow-up，
继续在 `.worktrees/t070` 上实现，避免从 main 新建 worktree 时丢失未合并上下文。

## 目标

- 为 robot_wam 的 action label 增加可复现的 train-split normalization，并在训练、
  eval、checkpoint/config 中记录统计量路径和 loss 口径。
- 修正 eval 采样逻辑：固定 split 仍作为 eval 集合，但训练内抽样必须可复现且覆盖
  split 分布；完整 eval 继续支持 `--eval-batches 0 --max-eval-samples 0`。
- 对照 DreamZero 实现，明确当前 robot_wam action head 与 DreamZero action-token
  joint diffusion 的差异，并实现最小可跑的 action-token 路径或给出清晰的后续任务边界。

## 实施计划

1. 复核 `ref-DreamZero` 的 action/state register、action noise 和 Wan wrapper 代码，
   记录 DreamZero 的 action token 是否进入 backbone。
2. 为 robot_wam 增加 action stats 构建/加载：
   - 基于 train manifest 统计 `[24,7]` 或 per-dim action mean/std。

   - 如果本轮可控，实现 action token 加噪并让 Wan backbone 联合预测 action noise。

   - `py_compile`
   - `robot_wam --help` / `train-wan --help` / `eval-wan --help`
   - 小样本 stats + train/eval smoke，检查 normalized/raw metrics 和 eval 样本覆盖。

## 执行记录

### DreamZero action 处理复核

已复核 `ref-DreamZero`：

- `StateActionTransform` 将 action/state 归一化，配置中常用 `q99`；dataset 还支持
  relative action。
- `WANPolicyHead.forward` 对 normalized action 加 flow-matching noise，并计算
  action noise target。
- `CausalWanModel` 内有 `action_encoder`、`state_encoder` 和 `action_decoder`：
  noisy action 经 `action_encoder` 编成 action register，state 经 `state_encoder`
  编成 state register，二者与 video tokens 拼入同一个 transformer sequence。
- Wan backbone blocks 共同处理 video/action/state tokens，最后从 action token slice
  经 `action_decoder` 预测 action noise。

结论：用户记忆正确，DreamZero 的 backbone 确实参与 action token 去噪；task073/task074
的 robot_wam MLP action head 与 DreamZero joint video-action diffusion 不等价。

用户随后要求直接改成 DreamZero 相同形式。本轮已在现有 DiffSynth `WanModel`
forward 外层实现最小 action-token 路径：action/state register token 追加到 Wan
self-attention 序列，backbone 参与 action token 去噪。

### 已实现

- `.worktrees/t070/src/pipeline/robot_wam.py`
  - 新增 `ACTION_STATS_SCHEMA_VERSION` 和 `action-stats` 子命令。
  - 新增 `ActionNormalizer`，支持 `q99` / `mean_std` / `min_max` 和
    `per_dim` / `per_horizon`。
  - Dataset 输出 normalized `action` 与 raw `action_raw`。
  - eval `max_eval_samples` 支持 `task_stratified` / `shuffle` / `head`，默认
    `task_stratified`，并记录 `selected_by_task`。
  - `train-wan` / `eval-wan` 要求显式 `--action-stats`。
- `.worktrees/t070/src/pipeline/robot_wam_wan.py`
  - `action_loss` 改为 normalized action flow-matching MSE。
  - 新增 `ActionTokenEncoder`、`StateRegisterEncoder` 和 `ActionTokenDecoder`。
  - normalized action 加噪后经 `ActionTokenEncoder` 编成 action token；state 经
    `StateRegisterEncoder` 编成 state register token；二者进入 Wan self-attention
    backbone 后，由 `ActionTokenDecoder` 从 action token slice 预测 action flow target。
  - 新增 `action_norm_mse`、`action_flow_mse`、`action_raw_mse`、`action_raw_rmse`。
  - `action_raw_mse/rmse` 由 `noisy_action - sigma * pred_action_flow` 重建 clean action 后
    反归一化计算。
  - `config.json` / eval JSON 记录 action stats、eval selection summary。
  - 旧外置 MLP action checkpoint 作为 `--init-lora` 时只恢复 LoRA，并在 model summary
    记录 ignored tensor 数量；新 action-token checkpoint 会严格恢复
    `state_register_encoder`、`action_encoder` 和 `action_decoder`。
- `.worktrees/t070/src/pipeline/robot_wam_model_fn.py`
  - Wan forward 支持 action/state register token 追加到 video token 后参与每个 DiT block。
  - 为 action/state register token 添加 1D RoPE freqs，并只对 video token slice 调用
    Wan head/unpatchify。
- `.worktrees/t070/doc/step_5_training_infra.md`
  - 记录 action-stats 命令、新 loss 语义、eval 分层抽样和 DreamZero action-token
    后端。
- `.worktrees/t070/doc/scripts_inventory.md`
  - 更新 `robot_wam.py` 入口说明。

### 当前边界

- 当前已经满足 DreamZero 的核心 action 形式：normalized action 加噪、action token 进入
  Wan backbone、从 action token slice 预测 action flow target。
- 尚未迁入 DreamZero 完整 `CausalWanModel` 的 blockwise causal attention mask、
  video/action/state block 对齐 mask、KV-cache 推理和 decoupled video/action noise
  schedule；因此这是最小可跑 action-token 对齐，不是逐行复刻 DreamZero wrapper。

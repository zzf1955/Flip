## 背景

task051 / task052 已经实现 Humanoid Everyday H1 两帧 RGB IDM，但直接从少量 RGB pair
回归 H1 26 维 action 只略优于均值 baseline。task054 已经复现 AdaWorld LAM action
encoder：输入 `(frame_t, frame_{t+1})`，输出 32 维 continuous latent action `z_t`，
并保存 latent artifact。当前需要基于 AdaWorld latent action 训练一个 action decoder，
把 `z_t` 解码为 H1 具体 action。

说明：`.worktrees/t055` / `feat/t055-h1-arm-mesh-overlay` 已存在但未在 `doc/tasks/`
中登记，本任务使用 056 避免覆盖已有工作树。

## 目标

1. 确定 action decoder 架构：以 `z_t [32] -> action_t [26]` 为主线，优先使用小 MLP。
2. 新增独立训练 pipeline，读取 AdaWorld latent artifact 与 H1 LeRobot action label。
3. 明确时序对齐为 `(frame_t, frame_{t+1}) -> z_t -> action_t`。
4. 支持 train / validate / eval，输出 checkpoint、metrics、预测表和 loss 曲线。
5. 同步更新 `scripts/flip_run.sh`、`doc/scripts_inventory.md`、`doc/step_5_training_infra.md`
   和 `doc/requirement-log.md`。

## 范围

- 不重新训练 AdaWorld action encoder。
- 不加载 AdaWorld world model。
- 不替换现有 `humanoid_pair_idm`；新增独立 `adaworld_action_decoder` 入口。
- 第一版 decoder 使用 MLP baseline，必要时保留参数控制 hidden dim / depth / dropout。
- latent artifact 缺失、schema 不匹配、action label 维度不对时直接报错，不做隐式 fallback。

## 实施计划

1. 复用 task054 的 `latent_actions.npz` schema，并从对应 parquet 按 episode / chunk /
   `rel_frame_t` 读取 H1 26 维 action label。
2. 实现 latent dataset、episode/sample split、target normalization、MLP decoder。
3. 实现 train / validate / eval CLI，保存 checkpoint、`train_loss.csv`、`eval_loss.csv`、
   `best_checkpoint.pt`、预测 CSV 和 metrics JSON。
4. 将入口接入 `scripts/flip_run.sh`。
5. 更新文档，写清 decoder 架构选择、artifact 输入、训练命令和局限。
6. 运行 compile/help/smoke 验证。

## 验收标准

- `python -m compileall src/pipeline/adaworld_action_decoder.py` 通过。
- `scripts/flip_run.sh adaworld_action_decoder --cuda <id> -- train --help` 可用。
- 能基于 task054 的 latent artifact 跑通小样本 smoke，loss 非 NaN。
- checkpoint validate 能复用训练时 split/config 并生成 held-out 指标。
- 文档说明 MLP decoder 是当前合理 baseline，以及何时需要升级到序列模型。

## 测试要求

- compileall 覆盖新增 pipeline。
- train / validate / eval help 覆盖。
- H1 小样本 smoke：先 extract latent，再训练 decoder 若干 step。

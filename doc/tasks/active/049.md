## 背景

task47 / task48 已经实现并扩展了 Wan VAE arm-hand IDM：从真实 robot 视频重建
`action.ee_action` 与 `action.hand_cmd`，用于验证生成视频是否保留 action cue。
当前训练直接对完整 24 维 action 计算 loss，但第一人称视频中不一定能看到完整胳膊、
腿部或其它身体部位；画面外的关节会趋向默认状态，导致这些 action 维度难以从视频
判断。手部通常更准，因为手在画面内时可见性更高，监督信号也更可靠。

三阶段训练的第二阶段会使用 robot mesh 构造机器人区域并做模糊，这部分 mesh / 投影
信息可以初步判断每一帧哪些机器人关节在画面中。新的 IDM 训练策略应按帧计算
visible joint / visible action mask，loss 只计算画面内可见关节对应的 action 维度。
mask 产物需要稳定保存，后续还可能用于其它 action-aware 训练或评估。

## 目标

1. 为每个 robot segment / clip 计算逐帧可见关节 mask，并映射到 action 维度 mask。
2. 在 Wan VAE IDM 训练、验证和 eval 中支持 masked action loss / masked action metric。
3. 持久化保存 mask 产物和索引，便于复用、检查和后续实验。
4. 只在当前三个 H2R 任务上运行和验证：
   - `Inspire_Collect_Clothes_MainCamOnly`（pick up cloth / collect clothes）
   - `Inspire_Put_Clothes_into_Washing_Machine` / `Inspire_Put_Clothes_into_Washing_Machine_MainCamOnly`（wash machine）
   - `Inspire_Pickup_Pillow_MainCamOnly`（pick up pillow）

## 范围

- 基于现有 robot mesh / stage2 blur 相关产物或可复算流程，得到每帧 joint visibility。
- 定义 joint visibility 到 `action.ee_action` 12 维和 `action.hand_cmd` 12 维的映射。
- 当前 IDM 标签只有 arm + hand action；不要为了腿部额外发明不存在的 action 标签。mask
  数据结构可以预留 joint-level 信息，但本任务训练 loss 只覆盖现有 24 维 action。
- 新增或扩展 `src.pipeline.wan_vae_idm` 的 dataset、loss、validate、eval 输出。
- 输出 mask artifact，建议使用稳定路径，例如
  `training_data/action_mask/<task>/<episode>/<seg>.npz`，并配套 `index.jsonl` 或等价索引。
- 更新 `doc/pipeline/training_infra.md`、`doc/infra/code_structure.md` 和必要的 requirement log。
- 不跑其它旧任务，不包含 `Inspire_Put_Clothes_Into_Basket`。

## 实施计划

1. 梳理 stage2 robot mesh / blur / SAM2 mask 产物路径，确认能否直接复用 mesh 投影；如果缺少
   现成产物，新增显式 precompute CLI，不做隐式 fallback。
2. 定义可见性规则：关节投影在图像范围内，并且对应 mesh / robot mask 在该帧有足够像素覆盖；
   阈值和 camera / image 尺寸写入 mask metadata。
3. 定义 action mask 映射：将左右臂末端 action、左右手 hand command 映射到对应可见关节或
   body part。映射表必须显式保存在代码和文档中。
4. 为 `wan_vae_idm train` 增加读取 mask 的路径参数和开关；clip-level target 仍可保持均值，
   但 loss 使用同一 clip 窗口内的可见 action mask 聚合结果。
5. 实现 masked MSE：分母只统计 visible action 维度；如果某个样本没有任何可见维度，应由
   显式 dataset filter 或明确错误处理决定，不允许静默当作 full-visible 或 default mask。
6. validate / eval 输出中同时保留 unmasked 指标和 masked 指标，并输出每个样本的可见维度数量、
   arm / hand 可见比例，便于判断指标是否被少量可见维度主导。
7. 在三个任务上分别运行小规模 smoke，再运行可对比 task47 / task48 的正式或中等规模训练；
   汇总 masked 与 unmasked 的 held-out 表现差异。

## 验收标准

- 三个指定任务均能生成可复用的 visible joint / action mask artifact。
- mask artifact 中包含逐帧 joint mask、action 维度 mask、任务名、episode、segment、帧率、
  图像尺寸、阈值和版本信息。
- `wan_vae_idm train` 可以使用 mask 训练，loss 只在 visible action 维度上计算。
- `wan_vae_idm validate` / `eval` 输出 masked arm、masked hand、masked combined MSE，
  并保留 visible action count / ratio。
- 缺少 mesh、mask、action 标签、任务名不匹配或 mask 维度不匹配时直接报错。
- 结果文档说明三任务各自的 checkpoint、held-out 指标、可见比例，以及相对 task47 / task48
  unmasked IDM 的变化。

## 测试要求

- `python -m compileall src/pipeline/wan_vae_idm.py`，以及新增模块的 compileall。
- mask precompute 小样本 smoke：每个任务至少 1 个 episode / segment，检查 `.npz` 维度、
  metadata 和 action mask 非空统计。
- masked training smoke：每个任务用少量样本跑几十 step，确认 loss 可下降且 visible count
  日志正常。
- full 或中等规模 validate：三个任务分别用 best checkpoint 复算 held-out metrics。
- 如新增 CLI，至少运行 `--help` 和 `--max-samples` 级别的 smoke。

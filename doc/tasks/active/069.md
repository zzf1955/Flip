## 背景

task068 已经新增 H2R HDF5 Diffusion Policy BC 入口，并完成小样本 smoke。用户现在要求
使用完整 `data/h2r` 数据集训练并优化 Diffusion Policy 参数，而不是停留在 smoke 规模。

初步检查发现，`--tasks all` 会命中部分 episode 缺少旁路 mp4 文件的情况，例如
`video/grab_both_cubes_v1/episode_11/robot_camera.mp4` 缺失；训练实际读取的是 HDF5 中的
`cam_data/robot_camera`，因此完整训练应以 HDF5 为权威数据源，并把 mp4 仅作为可选对齐
检查信息。

## 目标

1. 支持完整 H2R HDF5 数据训练，不因缺失旁路 mp4 阻断。
2. 补齐长训必要能力，至少包括严格 checkpoint resume / init 训练。
3. 在完整 H2R 数据上跑 Diffusion Policy baseline 与参数 sweep。
4. 根据验证集 denoising loss、sampled action MSE 和 per-horizon MSE 选择推荐参数。
5. 输出可复现训练命令、checkpoint 路径、指标和后续改进建议。

## 范围

- 数据：`data/h2r/v1/data/*/episode_*.hdf5` 下的完整 H2R HDF5 episode。
- 训练：offline behavior cloning，仅训练 action diffusion policy。
- 评估：held-out episode split 上的 denoising loss、sampled normalized action MSE、
  per-horizon MSE。
- 不做真机、仿真闭环或 World Model / future video prediction。
- 不引入宽泛 fallback；字段、维度、checkpoint schema 或配置不一致时直接失败。

## 实施计划

1. 统计完整 H2R 数据：
   - task / episode 数量；
   - HDF5 camera / state / action 字段完整性；
   - 缺失 mp4 的 episode 数量，仅作为数据质量记录。
2. 更新 H2R Diffusion Policy 入口：
   - 训练发现 episode 时以 HDF5 camera 为权威；
   - 输出 missing video 统计；
   - 增加严格 `--resume-checkpoint` / `--init-checkpoint` 能力；
   - 保存 optimizer、step、config、normalization、summary 并恢复一致性。
3. 跑完整数据 inspect 和训练 smoke：
   - 验证 `--tasks all` 能构建 train / val；
   - 验证 resume / eval。
4. 跑参数优化实验：
   - baseline：`obs_horizon=4,pred_horizon=16,hidden_dim=256,depth=6,diffusion_steps=32`；
   - 对 horizon、模型容量、dropout、diffusion steps 进行小规模 sweep；
   - 根据验证集指标选择推荐配置。
5. 更新文档：
   - 记录完整数据训练命令；
   - 记录 sweep 表和最佳 checkpoint；
   - 更新数据质量注意事项。

## 验收标准

- `scripts/flip_run.sh h2r_diffusion_policy -- inspect --tasks all` 能在完整 H2R HDF5 数据上成功。
- 训练入口支持从 checkpoint 严格 resume，且 config / shape 不一致会失败。
- 至少完成一个完整数据 baseline 训练，并保存 `best_checkpoint.pt` / `last_checkpoint.pt`。
- 至少完成两组参数变体对比，形成推荐参数。
- `eval` 能恢复推荐 checkpoint 并输出 `eval_summary.json` / `predictions.csv`。
- 文档记录数据规模、命令、指标、推荐参数和限制。

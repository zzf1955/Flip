## 背景

task062 已经新增 G1 专用 IDM 入口，并在 `Inspire_Collect_Clothes_MainCamOnly`
上完成了初版 Transformer / AdaWorld 两条路线训练与 H2R full_eval action 复算。
但 task062 的实现和实验仍有两个限制：

- 只对 Collect Clothes 做了正式训练；后续三任务汇总不等价于三个 G1 task 分别重训。
- G1 入口还没有完整迁移 task063 / task064 的最佳结构；当前 G1 Transformer 更接近初版
  pair IDM，G1 AdaWorld decoder 也还是基础 MLP 口径。

本任务需要把 H1 上最新两条 IDM 方法迁移到 G1 三个 task，分别训练并用统一
action-label 误差表比较 H2R 生成视频的动作一致性。

三任务口径固定为：

- `Inspire_Collect_Clothes_MainCamOnly`：in-task。
- `Inspire_Put_Clothes_into_Washing_Machine`：in-task；如 full_eval record 使用
  `Inspire_Put_Clothes_into_Washing_Machine_MainCamOnly`，需要显式映射到对应 raw action
  数据，不做隐式猜测。
- `Inspire_Pickup_Pillow_MainCamOnly`：OOD。

注意：用户提到的 `Baseline(均值,理论最差)` 这里按 IDM mean baseline 处理，即使用
对应 task 的 train split 24 维 action 均值作为常数预测。它是 MSE 下最优的常数预测
参考线，不是数学意义上的任意理论最差预测。

## 目标

1. 在 G1 三个 task 上分别重训两条 IDM：
   - task064 路线：RGB `motion_transformer_v2` 风格 pair IDM。
   - task063 路线：AdaWorld LAM latent + optimized residual decoder。
2. 每个 task 独立使用本 task 的 raw action label 和 episode-level split，不跨 task 混训。
3. action 目标固定为 24 维 `action.ee_action + action.hand_cmd`。
4. 训练和评估都优先启用 visible action mask；若 mask 缺失，先补齐或明确记录无 mask 口径，
   不静默混用 masked / unmasked 指标。
5. 在 H2R `full_eval` 的三任务 normal 样本上比较 `Ours`、`Mitty` 和
   `Baseline(均值,理论最差)`。
6. 最终主表固定为 4 列：

```text
Task, IDM Method, MSE, relative Error
```

其中 `IDM Method` 使用复合标签表达评估器与视频来源，例如：

- `Transformer/Ours`
- `Transformer/Mitty`
- `AdaWorld/Ours`
- `AdaWorld/Mitty`
- `Mean baseline`

## 范围

- 基于 task062 的 G1 独立入口继续开发；不要把 H1 `humanoid_pair_idm` /
  `adaworld_action_decoder` 改成大一统 G1/H1 混合入口。
- 允许把 task064 的 `motion_transformer_v2` 能力迁移到 `g1_pair_idm`：
  raw RGB diff / abs-diff motion stem、residual readout head、variance calibration loss、
  AMP、gradient accumulation、严格 checkpoint replay 等。
- 允许把 task063 的 decoder 能力迁移到 `g1_adaworld_action_decoder`：
  `residual_mlp` / `gated_mlp`、更宽 hidden、shared/per-dim/grouped head、
  weighted / SmoothL1 / variance loss、checkpoint 中保存完整配置。
- AdaWorld 路线每个 task 都要先提取本 task 的 latent artifact，再训练本 task decoder。
- H2R 评估只统计 `augment=normal`，跳过 hflip，避免翻转视频和未翻转 action label 不一致。
- 不把 Basket、BrainCo 或其它 G1 task 加入本任务。
- 不把当前 Collect 模型直接套到 Washing / Pillow 后汇报为同口径结果。

## 实施计划（分步骤）

1. 收口 task062 的 G1 数据层与 CLI，确认三任务数据、segment、raw action、full_eval record
   的 task 命名和 episode/segment 对齐关系。
2. 检查三任务 visible action mask：
   - 若 `training_data/action_mask_fullbody/<task>` 或等价 artifact 缺失，补跑对应
     `action_mask_precompute`。
   - 记录每个 task 的 mask 覆盖率、visible action ratio 和是否用于训练。
3. 迁移 task064 的 RGB `motion_transformer_v2` 到 G1 pair IDM，并保留 task062 旧
   `transformer` 作为 ablation / legacy replay。
4. 对三个 task 分别训练 G1 Transformer IDM，推荐先用 task064 风格配置起步：
   patch16、raw motion stem、residual head、variance loss、AMP、cosine scheduler。
5. 对三个 task 分别提取 AdaWorld latent：
   - 输出到 `tmp/g1_adaworld_action_encoder_<task>_full/latent_actions.npz`。
   - artifact 必须包含 task、episode、segment、frame 对齐、action target 和 mask 信息。
6. 迁移 task063 的 optimized AdaWorld decoder 到 G1，并对三个 task 分别训练 decoder。
7. 对每个 task / 每个 IDM checkpoint 运行完整 validate replay，保存 metrics 和 predictions。
8. 在两个指定 H2R full_eval run 上分别评估三任务 normal 样本：
   - `Mitty` run。
   - `Ours` run。
   - `Baseline(均值,理论最差)`：对应 task train action mean 常数预测。
9. 生成主表：

```text
Task, IDM Method, MSE, relative Error
```

   其中 `MSE = MSE(IDM(video), action_label)`，`relative Error` 定义为
   `(MSE - mean_baseline_mse) / mean_baseline_mse`。负值表示优于 mean baseline。
10. 同时保留诊断表：
    - GT video 的 `MSE(IDM(gt_video), action_label)`，作为 IDM 自身在真实视频上的误差下界参考。
    - arm / hand / arm_hand 分项 MSE。
    - Ours vs Mitty 的差值和相对改善。
11. 更新 `doc/pipeline/training_infra.md`、`doc/infra/code_structure.md`、
    `doc/requirement-log.md` 和本任务交付记录。

## 验收标准

- 三个 G1 task 各自都有独立 Transformer checkpoint 和 AdaWorld decoder checkpoint。
- 每个 checkpoint 都能通过严格 validate replay，并输出 `metrics.json` /
  `val_predictions.csv` 或对应命名文件。
- AdaWorld 三个 task 都有对应 latent artifact，不复用其它 task 的 latent。
- H2R full_eval 评估对三任务 normal 样本完整输出逐样本 action、逐样本 MSE 和汇总 CSV。
- 最终主表必须包含三任务全部行，列名严格为：

```text
Task,IDM Method,MSE,relative Error
```

- 主表中的 MSE 必须是模型预测 action 与 action label 的直接 MSE，不使用
  `IDM(video) vs IDM(gt_video)` 作为主指标。
- `relative Error` 的分母和 baseline 值必须在表或旁表中可追溯。
- 文档明确说明 Collect / Washing 是 in-task，Pickup Pillow 是 OOD。
- 文档明确说明 mean baseline 是常数预测参考线，不是任意意义上的理论最差预测。

## 测试要求

- `python -m compileall` 覆盖新增 / 修改的 G1 IDM 模块。
- 所有新增或扩展 CLI 的 `--help` 可运行。
- 三任务每条路线至少先跑小样本 smoke：
  - G1 Transformer smoke train + validate replay。
  - G1 AdaWorld latent smoke extract。
  - G1 AdaWorld decoder smoke train + validate replay。
- 正式训练后，对 6 个 checkpoint 运行完整 validate replay。
- 对 H2R full_eval 汇总脚本运行一次 dry-run / small sample，再运行完整三任务 normal 样本。

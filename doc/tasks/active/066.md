## 背景

task057、task061、task063 已在完整 Humanoid Everyday H1 数据上持续优化 AdaWorld IDM：

```text
(frame_t, frame_t+1) -> frozen AdaWorld LAM z_mu[32] -> decoder -> action_t[26]
```

当前最强 AdaWorld 路线为 task063 的 `residual_mlp hidden_dim=384 depth=4` shared-head
decoder，完整 held-out split 上 `action_mse=0.05023810639977455`。但 task063 始终复用
task057 预提取的固定 latent artifact，只优化约 `1.36M` 参数 decoder。相比 task064
RGB `motion_transformer_v2` 的 `action_mse=0.028906064108014107`，AdaWorld 路线仍有明显
差距。

AdaWorld LAM 原始训练目标不是 H1 action regression。下一阶段需要把动作监督梯度传回
LAM action encoder，判断冻结 encoder 是否已成为主要瓶颈，同时记录实际参数量和显存边界。

## 目标

1. 新增 H1 AdaWorld joint IDM 入口，直接从相邻 RGB 帧运行 AdaWorld LAM encoder 和 H1
   decoder，不依赖离线 latent artifact。
2. 支持冻结 encoder 对照和 encoder 联合微调；只把 `action_prompt`、LAM encoder、
   latent `fc` 计入 action encoder，不加载或训练 AdaWorld reconstruction decoder。
3. 支持从 task063 decoder checkpoint 严格初始化 decoder，并保存完整 joint checkpoint，
   供 held-out validate replay。
4. 明确记录 action encoder、decoder、总参数量和实际 trainable 参数量。
5. 在 H1 数据上完成 smoke 和至少一组冻结 / 联合微调对照，再决定完整长训配置。

## 范围

- 只覆盖 Humanoid Everyday H1 数据，不扩展到 G1。
- 监督语义保持 `(frame_t, frame_t+1) -> action_t[26]`。
- joint IDM 只使用 AdaWorld LAM `encode()` 路径；不加载 world model，不训练 LAM
  reconstruction decoder。
- 不保留隐式 fallback；checkpoint schema、数据 split、action schema 或 encoder tune
  配置不合法时直接失败。

## 实施计划

1. 扩展 AdaWorld LAM 加载函数，支持加载 checkpoint 后裁掉 reconstruction-only 模块。
2. 新增 `src.pipeline.adaworld_joint_idm`：
   - H1 RGB pair + action dataset；
   - task063 residual decoder 初始化；
   - frozen / joint encoder tune mode；
   - encoder / decoder 分组学习率；
   - 参数量汇总；
   - train / validate checkpoint replay。
3. 接入 `scripts/flip_run.sh adaworld_joint_idm`，更新训练基础设施文档和脚本清单。
4. 运行 compile、help、参数统计和 GPU smoke。
5. 运行可承受的冻结 / 联合微调对照，记录指标、显存和后续完整长训建议。

## 验收标准

- joint IDM 能从真实 H1 RGB pair 训练并保存 checkpoint。
- `--encoder-tune-mode frozen` 和联合微调模式都能运行，且 trainable 参数统计准确反映差异。
- joint checkpoint 可以通过 `validate` replay。
- 文档写清参数量、初始化方式、smoke / 对照指标和完整长训命令。

## 测试要求

- `python -m compileall src/pipeline/adaworld_action_encoder.py src/pipeline/adaworld_joint_idm.py`
- `scripts/flip_run.sh adaworld_joint_idm --cuda <id> -- train --help`
- 参数统计命令覆盖 frozen 和联合微调模式。
- H1 真实视频 frozen / joint GPU smoke。
- joint checkpoint `validate` replay。

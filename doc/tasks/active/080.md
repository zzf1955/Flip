## 背景

task079 的 G1 SAM3.1 smoke 主要覆盖每个 task 前 61 帧样本。Washing Machine 在这些样本上结果很差，
`robot`、`mechanical arm` 和当前 text->bbox 二阶段均为 `0/61`，但这个结论可能被抽样窗口影响：
Washing 前面帧里机器人可见区域很少，text prompt 在前 2 秒无法得到稳定 seed，导致后续分割基本为空。

为了判断 SAM3.1 是否真的不适合 Washing，或者只是前段抽样窗口导致失败，需要对更长的视频范围做实验。

## 目标

- 用 SAM3.1 多跑几个 G1 segment 视频，重点覆盖 Washing Machine。
- 至少完整跑通 Washing Machine 的一个 episode，而不是只取前 61 帧。
- 对完整 episode 使用多个 robot-only prompt，并保留 overlay 结果便于快速查看。
- 继续比较 text-only 和 text->bbox 二阶段方案，确认是否能因后半段更清晰机器人画面而改善。
- 用自动统计记录非空帧比例、面积、SAM2 baseline IoU / coverage，不人工依赖视频观察。

## 范围

- 必须覆盖：
  - `training_data/segment/Inspire_Put_Clothes_into_Washing_Machine/ep000/seg*_video.mp4`
  - 该 episode 当前包含 13 个 segment 视频。
- 每个选中 segment 默认处理全长 source frames，不能只处理 61 帧。
- Prompt 优先使用 robot-only 口径：
  - `robot`
  - `robot arm`
  - `robotic arm`
  - `mechanical arm`
  - `robot hand`
- 二阶段方案至少覆盖：
  - `--prompt-mode text_bbox`
  - `--bbox-include-text`
  - prompt: `robot`、`mechanical arm`
- 输出默认写入 `tmp/` 下 task080 专用目录，不直接污染正式 `training_data/g1_sam3_mask/`。

## 实施计划

1. 给 `g1_sam3_precompute` 增加明确的 episode 选择能力，避免完整 episode 实验依赖排序和
   `--max-segments-per-task` 的隐式行为。
2. 用 dry-run 校验 Washing `ep000` 的 segment 数、全帧数和 chunk 数。
3. 运行前检查每张 GPU 显存，选择空闲 GPU。
4. 跑 Washing `ep000` 全 episode、全帧、多 prompt text-only sweep，并写 overlay。
5. 跑 Washing `ep000` 全 episode、全帧、text->bbox 二阶段 sweep，并写 overlay。
6. 如时间允许，再抽样其它 task 的多个 segment 作为对照。
7. 汇总 `index.json` / `prompt_sweep_index.json`，更新 `doc/sam3_g1_segmentation.md` 和任务执行记录。

## 验收标准

- `g1_sam3_precompute --dry-run` 能明确选择 Washing `ep000`，并显示 13 个 segment。
- 至少一个 Washing 完整 episode 的 SAM3.1 text-only sweep 跑通，无 OOM。
- 至少一个 Washing 完整 episode 的 SAM3.1 text->bbox sweep 跑通或记录明确失败原因。
- 输出包含 `.npz`、`.json`、overlay `.mp4` 和 sweep index。
- 文档记录：
  - 运行命令、GPU、显存状态。
  - 每个 prompt 的非空帧比例、平均面积、SAM2 IoU / coverage。
  - 与 task079 61 帧结论的差异，特别说明前段机器人可见区域少是否是主因。

## 测试要求

- `python -m compileall -q src/pipeline/g1_sam3_precompute.py`
- `scripts/flip_run.sh g1_sam3_precompute -- ... --dry-run`
- 至少一次真实 SAM3.1 episode precompute。

## 当前结论

- task079 Washing 前 61 帧的全空结论不能外推到完整 episode；full `ep000` 上
  `robot` prompt 可以分割出大部分 G1，说明主要问题是前段机器人可见区域太少。
- 纯 SAM3.1 在 Washing 上效果为“一般”：后段大多稳定，但 `seg00` 仍弱，`seg08`
  IoU 偏低，且尚未做人工 overlay 复核。
- `text_bbox + robot` 比 text-only 略好，主要改善早期 seed，但不是质变。
- `text_points + robot` 可以进一步改善 `seg00`，但会把后段 mask 明显放大；完整 episode
  IoU 降到 `0.610`，不适合作默认整机 blur mask。
- Collect `ep000` 纯 SAM3.1 text 非空率高但过分割明显，IoU 只有 `0.469`；Pickup
  `ep000` 相对更干净，IoU `0.706`。
- `robot arm` prompt 不适合整机 blur，因为面积和 IoU 都显示它更像局部分割。

## 背景

现有 Transformer IDM 与 AdaWorld IDM 都主要围绕 Humanoid Everyday H1 数据实现，
但用户需要把同样的两条 IDM 路线放到 Unitree G1 pick-up-cloth 数据上验证。G1 数据与
H1 数据的 LeRobot layout 和 action schema 不同：G1 使用
`action.ee_action` 12 维与 `action.hand_cmd` 12 维，评估视频也来自已有 H2R
`full_eval` run。

## 目标

1. 新增 G1 专用 Transformer pair IDM，不把 H1 `humanoid_pair_idm` 改成大一统入口。
2. 新增 G1 专用 AdaWorld action encoder / decoder，不改变 H1 AdaWorld 入口默认行为。
3. 在 `Inspire_Collect_Clothes_MainCamOnly` 上训练 Transformer 与 AdaWorld decoder。
4. 训练正常后，在指定两个 `full_eval` run 的 pick-up-cloth normal 样本上评估并比较。

## 范围

- 只覆盖 `Inspire_Collect_Clothes_MainCamOnly`。
- action 只使用 arm + hand，即 `action.ee_action + action.hand_cmd` 24 维。
- 训练优先读取 `training_data/segment/<task>`，通过 segment joints 回查 raw G1 action。
- 允许读取已有 `training_data/action_mask_fullbody` 做 masked loss / metric。
- 不重构 H1 IDM 入口，不扩展到 washing / pillow / basket。

## 实施计划（分步骤）

1. 新增 G1 pair sample / action resolver / mask resolver 的独立数据层。
2. 新增 `g1_pair_idm` 入口，复用现有 Transformer 架构思路训练 24 维 action。
3. 新增 `g1_adaworld_action_encoder`，从 G1 segment 两帧提取 AdaWorld latent。
4. 新增 `g1_adaworld_action_decoder`，从 G1 latent artifact 训练 24 维 decoder。
5. 新增 `g1_h2r_pair_idm_eval`，只评估两个指定 full_eval run 的 pick-up-cloth normal 样本。
6. 接入 `scripts/flip_run.sh`，补充文档和需求日志。
7. 跑 CLI / compile / smoke 测试；若训练耗时过长，先交付可运行入口和 smoke 结果。

## 验收标准

- G1 Transformer 与 G1 AdaWorld 路线都有独立 CLI。
- G1 训练样本能正确对齐 segment video、raw action 和可选 action mask。
- 训练输出包含 checkpoint、best checkpoint、loss CSV、metrics 和 predictions。
- full_eval 输出逐样本 action、逐样本 metric、按 run 汇总和 Baseline/Ours delta。
- 缺少视频、action、latent、mask 或任务不匹配时直接失败，不做静默 fallback。

## 测试要求

- `python -m compileall` 覆盖新增 Python 模块。
- 所有新增 CLI `--help` 可运行。
- G1 Transformer 小样本 smoke 训练。
- G1 AdaWorld latent smoke + decoder smoke。
- full_eval 每个 run 至少 1 条 pick-up-cloth normal 样本 smoke。

## 背景

task067 已验证 Wan2.2-TI2V-5B + DreamZero-style LoRA 的离线 video-action world-action
model 原型，并确认 FLIP 目标不是 human-to-robot paired translation，而是从机器人第一人称
操作视频和机器人 state 预测未来视频与 action chunk。

当前后续要求有两点：

1. 当前模型的输入输出必须收敛到 robot-only WAM：
   - 输入只有 robot video history 和 robot state；
   - 训练标签为 future robot video 和 future action；
   - 数据链路不应读取、缓存或依赖 human video。
2. 重构训练 infra：
   - 预制 T5 text cache；
   - 预制 VAE latent cache；
   - 主模型训练加入数据预取；
   - 禁止把大模型先加载到 CPU 内存再搬运，避免触发系统内存 OOM。

## 目标

1. 新增 robot-only WAM 数据规范与检查入口，确保数据样本只包含机器人视频、机器人 state 和
   future action。
2. 新增 T5 cache 预制入口，把文本条件离线编码并保存为训练可直接读取的 cache。
3. 新增 VAE cache 预制入口，把 robot video history / future robot video 离线编码为 Wan VAE
   latent cache。
4. 新增或更新 WAM 训练入口，使训练只读取 cache / state / action，不在训练进程内加载 T5 或
   VAE。
5. 为训练 DataLoader 增加显式 prefetch 配置，降低 GPU 等待数据的概率。
6. 更新文档，记录 robot-only IO、cache schema、低内存模型加载规则和推荐运行命令。

## 范围

- Backbone：沿用 task067 的 Wan2.2-TI2V-5B + DreamZero-style LoRA / action-state register
  路线。
- 输入：robot video history、robot state、可选 text prompt cache。
- 输出 / 训练标签：future robot video latent、future action chunk。
- Human video 不属于本任务模型 IO / cache 路径；raw H2R HDF5 中可以存在 `human_camera`，
  但 manifest/cache/training batch 不得引用、保存或依赖它，cache 中出现 human/control 字段
  应直接失败。
- T5 / VAE 只在离线 cache 预制入口加载；主模型训练不得加载 T5 / VAE。
- 大模型权重加载必须使用 mmap / safetensors direct device / low CPU memory 的确定性路径，
  禁止先完整载入 CPU 匿名内存再搬运。
- 不做真机闭环，不做 Diffusion Policy BC，不改 task069 路线。

## 实施计划

1. 复核 task067 代码和当前 FLIP 训练 infra，定位 Wan / DreamZero-style WAM 可迁入或可封装的
   最小入口。
2. 设计 robot-only WAM dataset manifest / cache schema：
   - episode id、frame index、robot video source、state source、action source；
   - text cache path；
   - observation latent cache path；
   - future latent cache path；
   - state/action shape、dtype、normalization 元数据。
3. 实现数据检查入口：
   - 验证样本不含 human video；
   - 验证 state/action/video horizon 对齐；
   - 输出 episode / sample 统计和 schema summary。
4. 实现 T5 cache 预制入口：
   - 支持固定 prompt 或 manifest prompt；
   - 保存 cache tensor 和 metadata；
   - 训练入口只消费 cache，不加载 T5。
5. 实现 VAE cache 预制入口：
   - 只编码 robot video；
   - 保存 observation / future latent；
   - 记录 Wan VAE 配置、dtype、shape 和 source frame span；
   - 训练入口只消费 latent cache，不加载 VAE。
6. 实现 robot-only WAM 训练入口或改造既有入口：
   - 输入 cache latent + state；
   - 输出 future latent / action；
   - checkpoint 只保存 trainable LoRA + action/state 模块；
   - 加入 DataLoader prefetch 参数；
   - schema / checkpoint 不一致时直接失败。
7. 更新文档和脚本入口：
   - `scripts/flip_run.sh` 子命令；
   - `doc/step_5_training_infra.md`；
   - `doc/scripts_inventory.md`；
   - `doc/requirement-log.md`。

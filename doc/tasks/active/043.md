## 背景

`src.pipeline.evaluate_mitty_models` 当前承担 run 解析、数据 split、生成视频、Local FID
辅助视频、指标汇总和 CLI 参数定义，脚本接近千行，后续维护成本高。

mask-region 指标中，Local FID 已按 robot mask bbox crop 的局部口径计算；区域 FVD
仍使用前景/背景黑底视频口径，字段为 `foreground_black_fvd` / `background_black_fvd`，
与 Local FID 的局部区域口径不一致。

当前 `--write-local-videos` 输出只写局部 crop 视频和三列 crop 对比，不能直接在原始画面上
看出哪些区域参与了 Local FID / Local FVD 计算，人工检查样本时不够直观。

## 目标

1. 拆分 Mitty 离线 eval 脚本，降低入口文件体积并让生成、配置、local 可视化逻辑分模块维护。
2. 将 mask-region 的区域 FVD 改为 Local FVD：用与 Local FID 一致的 robot mask bbox crop
   视频计算 S3D Frechet 距离。
3. 改进 `local_fid/` 输出，让视频能明确标出参与局部指标计算的区域。
4. 同步更新训练/评估文档。

## 范围

- 修改 `src/pipeline/evaluate_mitty_models.py` 及新增的评估辅助模块。
- 修改 `src/tools/eval_metrics.py` 的 Local FVD 指标计算与输出字段。
- 更新 `doc/step_5_training_infra.md` 和必要的需求记录。

## 实施计划

1. 提取 eval run/spec、参数解析、生成视频、Local crop/可视化到 `src/pipeline/eval_mitty/`。
2. 在 `src.tools.eval_metrics` 中增加 mask bbox crop 视频特征路径，输出 `foreground_local_fvd`。
3. 移除离线 eval summary 中旧黑底 FVD 字段，保留全局 FVD。
4. 为 Local 视频增加原始画面 overlay/compare 输出和索引字段。
5. 运行轻量 import/CLI 测试；如果 GPU 指标无法跑，说明未跑原因。

## 验收标准

- `python -m src.pipeline.evaluate_mitty_models --help` 可正常运行。
- 入口脚本明显变小，核心逻辑分散到命名清晰的模块。
- 有 mask-region 指标时输出 `foreground_local_fid` 和 `foreground_local_fvd`，不再输出
  `foreground_black_fvd` / `background_black_fvd`。
- `local_fid/` 包含可视化参与计算 bbox 的视频或对比视频。
- 文档描述与新字段、新视频输出一致。

## 测试要求

- 至少运行 Python 编译或 import 检查。
- 至少运行 eval CLI help。
- 如有可用小样本，可运行 `--no-generate --no-fid` 级别的轻量指标路径；否则说明未运行。

## 背景

当前 G1 2s 数据已经接入 `src.pipeline.h2r_diffusion_policy`，state/action 对齐口径为
48 维 robot state 监督 48 维 robot action。已有 h128 d4 MLP denoiser 在 4096 train /
512 val、1000 steps 上的 action-space relative L2 基本平台化在 0.66 左右，说明继续只加
step 的收益有限。

## 目标

- 升级 Diffusion Policy 模型架构，优先增强 action horizon 上的时序建模能力。
- 保留同一 G1 2s 数据、同一 action-space 指标，重点观察
  `sampled_action_relative_l2_action`。
- 通过 smoke 和小规模训练确认新架构能跑通，并给出与当前 MLP baseline 的可比结果。
- 同步更新训练文档，记录新架构参数、命令和实验结论。

## 范围

- 修改 `src/pipeline/h2r_diffusion_policy.py` 的模型/CLI/checkpoint config。
- 更新 `doc/step_5_training_infra.md` 中 G1 Diffusion Policy 训练说明。
- 输出仍写入 `tmp/`，不直接写正式训练数据目录。

## 实施计划

1. 将当前 G1 2s 数据接入与 action-space 指标基线带入 task worktree。
2. 增加可选的时序 denoiser 架构，避免把 `pred_horizon * action_dim` 完全展平交给 MLP。
3. 跑编译、inspect/smoke，确认 checkpoint config 和 eval 可恢复。
4. 在同一 G1 小样本设置下跑新架构小训练，比较 relative L2。
5. 根据结果决定是否继续放大 hidden/channel 或启动长训。

## 验收标准

- `python -m compileall -q src/pipeline/h2r_diffusion_policy.py` 通过。
- G1 `inspect` 或小规模训练能跑通新架构。
- 新架构训练输出包含 `sampled_action_relative_l2_action`，且文档记录可复现命令与结果。
- 若新架构没有改善相对误差，文档应明确记录该负结果和下一步调整方向。

## 测试要求

- 编译检查。
- 至少一次 G1 新架构 smoke 训练。
- 至少一次可复现 seed 的 eval 或训练内 eval，指标包含 action-space relative L2。

## 当前结论

- 架构升级有效：旧 h128 MLP 4096/512、1000-step relative L2 约 `0.6636`，
  新 h128 temporal U-Net + ResNet encoder 4096/512、2000-step 降到 `0.54110`。
- 容量放大继续有效：h256 temporal U-Net + ResNet encoder 4096/512、2000-step 进一步
  降到 `0.52479`。balanced val 口径下，h128 `1,2,2` 为 `0.51864`，h256 `1,2,2`
  为 `0.50123`。h256 在旧 val 口径 step1000/1200/1400/1600/1800/2000 的 relative L2 分别为
  `0.54370` / `0.54193` / `0.53449` / `0.53024` / `0.52957` / `0.52479`。
- balanced breakdown 显示 residual error 主要来自 `action.robot_q_desired`，不是单一 task、
  hand action 或末端 horizon 独占。
- h256 `1,2,4` 在 800-step width probe 中仍为 `0.52959`，没有超过 h128/h256 `1,2,2`
  的 2000-step balanced 指标；单纯加宽不是当前最有效路线。
- action group loss weights `2,1` 的 800-step probe 为 `0.52769`，且 robot group
  `0.67053` 没有改善 h256 `1,2,2` 2000-step 的 `0.63882`；不建议把该加权配置作为
  默认路线。
- h256 `1,2,2` 从 2000-step best warm-start 六轮继续训练后达到 `0.47314`，
  robot group 也从 `0.63882` 降到 `0.59998`；但该路线已被 h512 temporal Transformer
  800-step probe 的 `0.45371` 超过。
- h512 temporal Transformer 以 30.03M 参数超过 33.10M 参数的 h256 U-Net 主线；
  继续 warm-start 到 cont11 停训前 best 达到 `0.38419`，说明当前收益来自 denoiser
  inductive bias 和 Transformer 主线延长训练，而不只是参数量。
- h768 temporal Transformer 虽然达到 63.95M 参数，但 fresh 800-step best 只有
  `0.44865`，最终 step800 为 `0.45351`；在当前预算下不如继续训练 h512 主线。

  h512 depth8 continuation 的 `0.38419`；后续深度扩容需要更强的分阶段训练策略。
- h384 `1,2,2` 虽然能跑到 70.96M 参数，但 fresh 800-step 只到 `0.52024`；除非做

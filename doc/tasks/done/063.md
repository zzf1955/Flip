## 背景

task061 已把 AdaWorld latent action decoder 从 task057 的小 MLP baseline 升级为
`residual_mlp`，并在同一套完整 H1 AdaWorld latent artifact 和 episode-level split 上
显著降低误差：

- task057 held-out `action_mse = 0.07853357493877411`
- task061 held-out `action_mse = 0.054645732045173645`
- task057 全量 eval `action_mse = 0.07298979163169861`
- task061 全量 eval `action_mse = 0.04235832020640373`
- task061 的 `action_pred_std_ratio_mean` 已提升到 held-out `0.8399375424935267`、
  全量 eval `0.8563885574157422`

当前推荐配置为：

`residual_mlp, hidden_dim=256, depth=4, dropout=0.02, lr=5e-4, weight_decay=1e-4,
betas=(0.9,0.95), cosine scheduler, min_lr_ratio=0.02, lr_warmup_ratio=0.05,
steps=3000, batch_size=1024`

这个配置已有约 `610k` 参数。对 `z_t[32] -> action_t[26]` 的低维回归问题来说，参数量
已基本够用，下一阶段不应只盲目堆大网络，而应系统判断容量、正则、优化器、loss 权重
和输出 head 是否才是剩余误差的主要瓶颈。

## 目标

1. 确认当前 `610k` 参数量是否已经接近容量甜点，避免把后续优化误判为继续加大模型。
2. 对 `residual_mlp`、`gated_mlp`、更宽/更深 MLP、不同 dropout / weight decay /
   learning rate 做同口径消融。
3. 基于 task061 的逐维预测结果，分析剩余高误差维度，重点关注
   `action_dim_05/06/07/08/09/10/22/23/25` 等维度。
4. 试验 per-dim weighted MSE、轻量 variance calibration loss、SmoothL1 等 loss 方向，
   判断能否改善最差维度和预测方差比。
5. 评估 shared trunk + per-dim head 或 group head 是否优于单一 shared head。
6. 形成二阶段推荐配置：保持 task061 默认，或把默认升级为新的架构 / loss / head。

## 范围

- 只优化 AdaWorld latent action decoder，即
  `src.pipeline.adaworld_action_decoder` 和对应文档。
- 继续复用 task057 全量 latent artifact：
  `tmp/adaworld_action_encoder_h1_full_t057/latent_actions.npz`
- 继续使用 task061/task057 同一数据根和 episode-level split：
  `data/humanoid-everyday-h1-chunks0-6-8-200`
- 不重新提取 AdaWorld latent，不训练 AdaWorld action encoder，不加载 AdaWorld world model。
- 不改变监督语义，仍是 `(frame_t, frame_{t+1}) -> z_t -> action_t`。
- 不把 H1 RGB Transformer IDM、G1 Pick-Up-Cloth IDM 或 H2R eval 扩进本任务。
- 不做静默 fallback；loss/head 配置、checkpoint replay、action dim 权重 schema 不合法时
  直接失败。

## 实施计划（分步骤）

1. 生成 task061 最佳 checkpoint 的逐维诊断表：
   - 输入：`tmp/adaworld_action_decoder_h1_full_t061/best_val_predictions.csv`
   - 输入：`tmp/adaworld_action_decoder_h1_full_t061_eval_best/predictions.csv`
   - 输出：`tmp/adaworld_action_decoder_t063_analysis/per_dim_summary.csv`
   - 排序维度：MSE、normalized MSE、R2、correlation、pred std ratio。
2. 先跑低成本容量 / 正则 / 优化器 sweep，每个候选先跑 `steps=1500`：
   - `residual_mlp hidden=192 depth=4 dropout=0.02 lr=5e-4 wd=1e-4`
   - `residual_mlp hidden=384 depth=4 dropout=0.02 lr=5e-4 wd=1e-4`
   - `residual_mlp hidden=256 depth=6 dropout=0.02 lr=5e-4 wd=1e-4`
   - `residual_mlp hidden=256 depth=4 dropout=0.00 lr=5e-4 wd=1e-4`
   - `residual_mlp hidden=256 depth=4 dropout=0.02 lr=3e-4 wd=1e-4`
   - `residual_mlp hidden=256 depth=4 dropout=0.02 lr=8e-4 wd=1e-4`
   - `residual_mlp hidden=256 depth=4 dropout=0.02 lr=5e-4 wd=1e-5`
   - `gated_mlp hidden=256 depth=4 dropout=0.02 lr=5e-4 wd=1e-4`
3. 选出 2 个候选跑完整 `steps=3000`；若 3000 step 仍持续下降，再延长到 `steps=5000`。
4. 如果容量 / 优化器 sweep 收益有限，增加 loss 方向：
   - 固定 per-dim weighted MSE，权重来自 task061 baseline 的 per-dim residual 统计。
   - MSE + variance calibration penalty，`lambda in {0.01, 0.03, 0.1}`。
   - SmoothL1 / Huber，`beta in {0.5, 1.0}`。
5. 如果 loss 方向仍不能改善高误差维度，增加 head 方向：
   - shared trunk + per-dim heads。
   - shared trunk + action group heads；如果 action dim 语义不足，先不强行分组。
6. 对最佳候选运行 `validate` replay 和全量 `eval`，并和 task061 / task057 做表格对比。
7. 更新 `doc/step_5_training_infra.md`、`doc/scripts_inventory.md`、
   `doc/requirement-log.md` 和本任务交付记录。

## 验收标准

- 至少产出 task061 最佳模型的逐维诊断表，明确当前最高 MSE / 最低 R2 / 方差不足维度。
- 至少完成 8 个低成本候选 sweep，并保存每个候选的命令、输出目录和关键指标。
- 至少完成 2 个完整候选训练，并基于同 split held-out 指标和全量 eval 指标给出推荐。
- 如果新候选优于 task061，held-out `action_mse` 应低于 `0.054645732045173645`，
  或在总 MSE 接近时显著改善高误差维度和 `action_pred_std_ratio_mean`。
- 如果新候选未优于 task061，需要明确说明瓶颈更可能来自 latent 信息量、loss 权重还是
  head 结构，并保留 task061 配置为推荐默认。
- 最佳 checkpoint 必须能通过 `validate` replay；全量 `eval` 必须输出 `metrics.json`
  和 `predictions.csv`。

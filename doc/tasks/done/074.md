## 背景

task073 已完成 H2R top1157 robot_wam 固定 split、三组 39,024-step 完整训练和
完整 fixed eval。训练内 best 为 `r16_lr1e-4_aw1_s39024_eval512`，但完整 eval
显示 OOD action loss 很高。用户要求本轮直接提高 LoRA rank，先试 `256/512/1024`，
只要参数量和显存没有爆，就继续往上加。

`robot_wam` 入口仍在 `.worktrees/t070` / `feat/t070-robot-only-wam-cache-prefetch`，
尚未合并到 root `main`，因此本任务继续在 `.worktrees/t070` 运行训练。task 文档
记录在 root `doc/tasks/done/074.md`。

## 目标

1. 在 task073 固定 split 上做高 rank LoRA 扩容实验：
   - `rank=256`
   - `rank=512`
   - `rank=768`
   - `rank=1024`
2. 先用真实 DiT 加载做短 smoke，确认参数量、checkpoint size、显存和恢复路径。
3. 对能跑通的 rank 启动完整训练，保持 task073 的固定 eval 口径：
   - train：`h2r_top1157_s8_fixed_v1/train.jsonl`
   - in-task eval：`eval_in_task.jsonl`
   - OOD eval：`eval_ood.jsonl`
   - best metric：`eval_mean_loss`
4. 若 `rank=1024` 仍能稳定跑通且显存余量足够，再继续试更高 rank；若 1024 OOM，
   按用户追加要求补测中间档 `rank=768`。
5. 输出 summary，按固定 eval loss 排序，并明确高 rank 是否改善 OOD。

## 实验口径

固定数据：

- T5 cache：`training_data/cache/t5/robot_wam_h2r_top1157_s8`
- VAE cache：`training_data/cache/vae/robot_wam/h2r_top1157_s8_160x320`
- split：`training_data/robot_wam/splits/h2r_top1157_s8_fixed_v1`

训练基础参数：

- `lora_attn_types=self,cross`
- `lora_attn_projections=q,k,v,o`
- `state_tokens=4`
- `state_hidden_dim=1024`
- `action_hidden_dim=512`
- `action_depth=3`
- `action_loss_weight=1`
- `best_metric=eval_mean_loss`

默认先沿用 task073 中更稳定的 `lr=1e-4`。如果高 rank 明显不稳定，再记录后续降
learning rate 的必要性；本任务首轮不隐式 fallback 到旧 rank。

## 实施计划

1. 运行 `rank=256/512/1024` 的真实 DiT 2-step smoke，并在 1024 OOM 后补测
   `rank=768`：
   - `max_train_samples=2`
   - `max_eval_samples=2`
   - `eval_every=1`
   - `save_steps=1`
   - `--no-skip-dit-load`
2. 对 smoke 通过的 rank，记录：
   - trainable parameter count
   - checkpoint tensor count / size
   - GPU memory usage
   - `eval_mean_loss` 字段是否正常
3. 启动完整训练：
   - `max_steps=39024`
   - `eval_every=5000`
   - `eval_batches=512`
   - `max_eval_samples=512`
   - `save_steps=5000`
4. 汇总：
   - `summary.csv`
   - `summary.md`
   - checkpoint key audit
5. 如有新 best，跑完整 fixed eval：
   - `eval-wan --eval-batches 0 --max-eval-samples 0`

## 验收标准

- 至少完成 `rank=256` 真实 DiT smoke。
- 对每个尝试的 rank，明确记录通过、OOM、参数过大或训练异常。
- 对能完整训练的 run，保存 `config.json`、`train_log.jsonl`、`train_summary.json`、
  `best_summary.json` 和 `best_checkpoint.safetensors`。
- 汇总表按 `eval_mean_loss` 排序。
- 若出现新 best，完成完整 fixed eval，并与 task073 best 对比。
- 不自动 commit。

结论：

- 单卡容量上，`rank=768` 可跑满；`rank=1024` 在当前 24GB GPU + AdamW 配置下不可行。
- 效果上，单纯把 rank 提到 256/512/768 没有刷新 task073 的 `rank=16` sampled best。
- 因为没有新 sampled best，本轮未追加完整 fixed eval；完整 fixed eval 仍以 task073 的
  `r16_lr1e-4_aw1_s39024_eval512` 结果作为当前最终参考。

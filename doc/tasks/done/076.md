## 背景

用户需要在 G1 新数据上按 2s、原始 30fps 口径重新训练三阶段模型。现有
`seedance_clip.py`、`make_pair.py` 和 `make_robot_pair.py` 仍以 1s/16fps/17帧
为主，`make_pair.py` 的 `2s` 也只是 2s@16fps/33帧，不能直接作为新的 30fps
训练数据。

## 目标

- 交付 2s@30fps 的原始机器人视频切片数据。
- 交付 Seedance 4s human 源视频对应的 2s@30fps 切片数据。
- 交付基于 SAM2 mask 的 2s@30fps 分割+模糊机器人切片视频。
- 第二阶段 blur_r2r 数据按 2s 非重叠步长切片，避免在大量 robot-only 数据上使用
  0.5s 或 1s 密集滑窗。

## 范围

- 新增或改造切片工具，使 2s@30fps 口径不与现有 `1s` / 旧 `2s` 数据混淆。
- 输出目录使用明确 duration label，例如 `2s61f30`，并在 manifest 中记录
  `fps`、`num_frames`、`clip_start_frame`、`source_frame_indices`、`clip_stride`。
- 生成数据优先覆盖当前 G1 canonical tasks：
  `Inspire_Collect_Clothes_MainCamOnly`、
  `Inspire_Put_Clothes_into_Washing_Machine`、
  `Inspire_Pickup_Pillow_MainCamOnly`。
- 更新相关文档与需求日志。
- 不启动正式三阶段训练；训练 cache 与训练命令只做后续建议或 smoke 验证。

## 实施计划（分步骤）

1. 复核现有 4s robot segment、Seedance 4s human 和 SAM2 mask 的目录、帧率和数量。
2. 实现参数化 2s@30fps 切片生成：
   - robot original：从 `training_data/segment/<task>/ep*/seg*_video.mp4` 切片。
   - Seedance：从 `training_data/seedance_direct/4s/<task>/ep*/seg*_human.mp4` 切片并重采样。
   - SAM2 blur：从 robot original 同步取帧，使用 `training_data/sam2_mask/` 对应 mask
     做局部 Gaussian blur。
3. stage2 blur_r2r 数据使用 2s stride；每条 4s segment 默认输出非重叠 2 个窗口。
4. 跑小样本 dry-run / smoke，确认视频帧数、fps、manifest 索引与 mask 对齐。
5. 生成正式数据并统计行数、目录、抽样元数据。
6. 更新 `doc/step_5_training_infra.md`、`doc/scripts_inventory.md` 和本任务记录。

## 验收标准

- 三类交付数据目录存在且各自写出 `manifest.jsonl` / `index.jsonl`。
- 抽样视频为 30fps，帧数与 manifest 的 `num_frames` 一致。
- robot original 与 SAM2 blur 的 `source_frame_indices` 完全一致。
- Seedance 切片 manifest 能追溯回 4s source、task、episode、seg、clip_start。
- stage2 blur_r2r 的 clip start 按 2s 步长生成。
- 不覆盖现有 `training_data/seedance_direct/2s` 或 `training_data/pair/*/2s` 旧数据。

## 测试要求

- `python -m compileall` 覆盖新增或修改的 pipeline 脚本。
- 小样本生成后用 ffprobe / OpenCV 校验帧数、fps、分辨率。
- 对至少一个 SAM2 blur 样本校验 mask 数量覆盖所有 `source_frame_indices`。
- 正式生成完成后输出每个 task 的样本数量统计。

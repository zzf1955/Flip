## 背景

当前 `blur_r2r` 数据构造存在两条路线：G1 主要依赖 SAM2 mask，human2robot 使用
SAM3/SAM3.1 robot-arm mask。两条链路的输入发现、mask 格式、采样方式和 pair 发布入口不统一，
导致后续 blur 数据构造与效果检查成本较高。

## 目标

- 新增统一的 SAM3 分割 pipeline，用同一套入口处理 human2robot 与 G1 视频源。
- 每段源视频只运行一次 SAM3 分割，生成可复用 mask artifact。
- 基于统一 mask artifact 构造 `blur_r2r` 2s/61f/30fps 样本。
- 分别从 human2robot 和 G1 采样少量 2s 视频跑通 pipeline，产出 mask/overlay/blur 预览供人工检查。

## 范围

- 新增或重构 `src/pipeline/` 下的 SAM3 mask 预计算、采样和 blur pair 构造代码。
- 接入 `scripts/flip_run.sh` 统一 launcher。
- 更新 `doc/pipeline/blur_r2r.md`、`doc/pipeline/sam2_sam3_masks.md` 及相关运行说明。
- 保留已有历史入口作为旧产物读取参考，但新流程不隐式 fallback 到旧 SAM2/G1 逻辑。

## 实施计划

1. 梳理现有 human2robot SAM3、G1 SAM2/SAM3、pair 构造脚本的数据格式。
2. 设计统一 clip manifest 和 mask artifact layout。
3. 实现统一 SAM3 分割入口，支持 `--dataset human2robot|g1`、2s clip 采样、resume 和预览输出。
4. 实现统一 blur pair 构造入口，读取同一 mask artifact 生成 `control_video`/`target_video`。
5. 更新 launcher 和文档。
6. 使用各自少量 2s 样本运行 smoke，记录输出路径和测试结果。

## 验收标准

- human2robot 与 G1 使用同一个 SAM3 分割入口运行。
- 同一个 mask artifact 可直接用于两个数据源的 blur 构造，不需要 SAM2 专用分支。
- 小样本运行输出包含原始视频、mask、overlay、blur control 和 target。
- 相关命令通过 `scripts/flip_run.sh` 暴露。

## 测试要求

- 在本地数据上分别对 human2robot 和 G1 采样少量 2s clip，完成 SAM3 mask 与 blur pair 构造。
- 记录命令、输出路径、失败原因或资源限制。

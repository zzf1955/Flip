## 背景

当前 Humanoid Everyday H1 的两帧 RGB IDM 已经切到 Transformer 作为默认骨干，
但现有实现仍然偏保守：patch 粒度较粗、时序建模只靠简单的 token 拼接，
优化器和学习率策略也还是通用默认值。前一轮对照显示，它虽然能优于小 CNN，
但在归一化空间和逐维方差上还有明显改进空间，部分 action 维度仍接近均值回归。

这次任务的目标不是重新定义监督口径，而是在保持 `mean(action[t:t+d])`
语义不变的前提下，把 Transformer IDM 的架构和训练细节往更合理的方向收紧。

## 目标

1. 提升 Humanoid H1 Transformer IDM 在归一化空间里的整体效果，重点看 normalized RMSE、逐维 L2 / R2 / correlation 和预测方差比。
2. 优化 Transformer 架构，使其更好地建模两帧之间的动作变化，而不是只做静态帧级表征。
3. 调整训练超参，重点补齐学习率、warmup、weight decay、dropout / 正则等对 Transformer 更敏感的细节。
4. 保持现有 `small_cnn` baseline 和 checkpoint 复算能力不变，方便新旧结果直接比较。
5. 把推荐配置回写到 `doc/step_5_training_infra.md`、`doc/scripts_inventory.md` 和 `doc/requirement-log.md`。

## 范围

- 只改 `src/pipeline/humanoid_pair_idm.py` 及其对应文档。
- 允许新增 Transformer 变体、优化器 / scheduler 选项、默认超参数和诊断指标。
- 不改任务切分口径，不再回到按 task 训练。
- 不引入静默 fallback；新的配置如果不合法，直接失败。

## 实施计划

1. 审计当前 Transformer 结构和训练曲线，找出高误差维度和低方差输出的主要原因。
2. 增强 Transformer 骨干，优先让两帧之间的 motion 信息进入显式建模路径。
3. 调整默认优化配置，加入更适合 Transformer 的学习率策略和 warmup。
4. 跑最小 smoke 和一轮可比对照，确认新默认不破坏现有 checkpoint 复算。
5. 记录新的推荐配置、实验现象和使用边界。

## 验收标准

- 新默认配置在验证集上的归一化指标优于当前主线默认，至少不劣于已有 Transformer baseline。
- 逐维输出中，至少一批高误差维度的表现出现明显改善，且预测方差不再接近塌缩。
- `validate` / `eval` 仍可复用 checkpoint，并且模型配置可以完整回放。
- 文档里写清楚推荐架构、学习率、warmup、权重衰减和适用场景。

## 测试要求

- `python -m compileall src/pipeline/humanoid_pair_idm.py`
- `python -m src.pipeline.humanoid_pair_idm train --help`
- 至少一个小规模 smoke 训练，确认 loss、eval、checkpoint 保存都正常。
- 至少一次验证集复算，确认新的 checkpoint 配置能正常 replay。

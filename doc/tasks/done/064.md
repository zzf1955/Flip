## 背景

当前 H1 IDM 的最强 RGB 路线是 `src.pipeline.humanoid_pair_idm` 的
`motion_transformer`。它在完整 Humanoid Everyday H1 held-out split 上已经优于
task061 AdaWorld optimized decoder，但训练预算仍偏小，预测方差低于目标方差，且部分
action 维度仍有明显低方差 / 高误差现象。

已有同口径基线：

- 数据：`data/humanoid-everyday-h1-chunks0-6-8-200`
- split：episode-level，`train_ratio=0.875`，`seed=42`
- train / val：`488936` train samples / `71486` held-out samples
- 当前 RGB motion Transformer：`action_norm_mse=0.320904`，
  `action_mse=0.051443`，`relative_l2_error=0.272016`，
  `pred_norm_var_mean=0.689259`

## 目标

1. 在当前 H1 视频上继续提升 RGB Transformer IDM 的 action 预测准确率。
2. 优先保持监督口径不变：`(frame_t, frame_{t+1}) -> action_t[26]`，
   即 `frame_delta=1`。
3. 降低 held-out `action_norm_mse` / `action_mse`，同时提升预测方差，减少接近均值回归的
   action 维度。
4. 保持旧 checkpoint 的 validate / eval replay 能力。
5. 把新的架构、loss、训练参数和推荐实验命令同步记录到文档。

## 范围

- 修改 `src/pipeline/humanoid_pair_idm.py` 及相关文档。
- 允许新增 `motion_transformer` 变体能力、训练 loss 选项、AMP / gradient accumulation、
  paired augmentation 和更细粒度 patch 实验参数。
- 不改变 H1 数据发现、episode split、action 对齐语义。
- 不回退到旧 `transformer` 作为主线；旧模型仅作为 legacy / ablation 保留。
- 不引入静默 fallback；配置非法时直接失败。

## 实施计划（分步骤）

1. 复核当前 `motion_transformer` 架构、训练参数和 per-dim 指标，确认第一批瓶颈。
2. 增加低风险训练能力：AMP、gradient accumulation、可配置 variance calibration loss，
   支持更长训练和 patch16 实验。
3. 增强 `motion_transformer`：优先加入 raw RGB diff motion stem 和 residual readout head，
   让模型更直接利用两帧运动信息并减少低方差输出。
4. 跑 compile/help/smoke 训练，确认 checkpoint、validate replay 和新增配置可用。
5. 给出正式长训实验矩阵，优先比较长训、低 weight decay/dropout、patch16 与新 motion stem。
6. 将推荐配置、命令、指标和注意事项写入 `doc/h1_idm_methods.md`、
   `doc/step_5_training_infra.md`、`doc/scripts_inventory.md` 和需求日志。

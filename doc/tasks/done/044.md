## 背景

当前离线 Mitty eval 的 `foreground_local_fid` / `foreground_local_fvd` 使用 SAM2
mask 的 bbox crop。机械臂区域细长且占比小，bbox 内仍会混入大量背景，导致局部
Frechet 指标仍不能足够精准地反映机械臂本体质量。

用户希望先实现 patch FID：按 mask 覆盖的细粒度 patch 集合提取特征并计算 FID，
评测时支持只跑 patch FID，并输出每帧被选中 patch 位置的 overlay 视频。

## 目标

1. 新增基于 SAM2 mask 的 `foreground_patch_fid` 指标。
2. 离线 eval 增加开关，只复用已有视频并只计算 patch FID。
3. 输出 patch 位置 overlay，使每一帧选中的 patch 可见。
4. 使用现有 `eval_h2r_80in_42ood_local_0506/.../in_task_eval` 数据做验证。

## 范围

- 修改 `src/tools/eval_metrics.py` 的 patch 选择、patch feature 和 patch FID 计算。
- 修改 `src/pipeline/evaluate_mitty_models.py` / `src/pipeline/eval_mitty/` 的 CLI、
  summary 字段与 patch overlay 输出。
- 更新训练评估文档和需求日志。
- 不实现 patch FVD / masked FVD；本任务只做 patch FID。

## 实施计划（分步骤）

1. 增加 mask patch 选择 helper：patch size、stride、coverage threshold、每帧/每视频上限。
2. 复用 Inception extractor，对 gen/GT 的同一组 patch 提取特征并计算 Frechet distance。
3. 增加 `--patch-fid-only` 评估开关，跳过 generation、LPIPS、全局 FID/FVD 和 bbox Local FID/FVD。
4. 增加 `--write-patch-overlays`，输出每帧 patch 位置 overlay 和 `patch_index.jsonl`。
5. 更新 summary CSV/JSON 字段。
6. 运行 Python 语法检查、单元/小样本 smoke，并用用户指定的 existing eval 目录验证。

## 验收标准

- `python -m src.pipeline.evaluate_mitty_models --help` 显示 patch FID 相关参数。
- 指定 `--patch-fid-only --no-generate` 时，不重新生成视频，只计算 `foreground_patch_fid`。
- summary 中包含 `foreground_patch_fid` 和 patch 数量字段。
- overlay 输出能看到每帧被选中的 patch 网格。
- 用户指定的 `in_task_eval` 目录可完成 patch FID smoke。

## 背景

当前评估脚本在启用 SAM2 mask-region Frechet 指标时，会把 mask 外区域置黑后对完整帧计算 `foreground_black_fid` / `foreground_black_fvd`。在 H2R 外观替换任务中，机器人区域只占画面一小部分，黑底或全局背景仍会稀释机器人外观差异，导致肉眼明显改善但 Frechet 指标优势很小。

SmartBrush 的 Local FID 做法是按 mask bounding box 裁剪局部区域后再计算 FID，更适合评估局部 object generation / replacement。

## 目标

- 将现有 mask-region 黑底 FID 替换为 bbox crop Local FID。
- 复用现有 SAM2 mask 对齐逻辑和 InceptionV3 FID 实现。
- 在 summary / CSV 中输出 Local FID 字段，避免继续使用误导性的黑底 FID 口径。

## 范围

- 修改离线评估指标实现及调用处。
- 如在线训练评估复用同一指标模块，也同步替换对应黑底 FID 口径。
- 更新 `doc/` 中关于 mask-region Frechet 指标的说明。
- 不实现 ROI-FVD；本任务只做 Local FID。

## 实施计划（分步骤）

1. 检查 `src/tools/eval_metrics.py`、`src/core/eval_metrics.py` 和 `src/pipeline/evaluate_mitty_models.py` 的 Frechet 指标调用路径。
2. 新增基于 mask bbox 的 Local FID crop helper：mask dilation / bbox / crop / resize 交给现有 Inception extractor。
3. 将原 `foreground_black_fid` 输出替换为 `foreground_local_fid` 或 `local_fid`，移除黑底 foreground FID 计算。
4. 保持局部 MSE/PSNR/SSIM 的 mask 内像素口径不变。
5. 更新 `doc/step_5_training_infra.md` 和必要的需求日志。
6. 运行聚焦测试或至少执行语法检查与小样本指标 smoke。

## 验收标准

- 启用 SAM2 mask-region metrics 时，summary 不再输出 `foreground_black_fid`。
- 输出 Local FID 字段，语义为 mask bbox crop 后的 FID。
- 缺失 mask、空 mask、视频/mask 尺寸不匹配仍直接报错。
- 原有全局 FID/FVD 和局部 MSE/PSNR/SSIM 行为不被破坏。

## 测试要求

- 运行 Python 语法检查。
- 使用现有 eval 目录或构造小样本执行 Local FID helper smoke，确认输出字段存在且旧黑底 FID 字段不再出现。

## 背景

当前 draft 中的下游控制验证原计划使用 DreamZero / World Action Model：输入视频和状态，
同时预测未来 action chunk 和未来视频。该路线模型较大，且会把实验目标扩展到 world model、
future video prediction 和离线 closed-loop rollout，训练与评估成本较高。

用户决定先将下游验证收窄为 Diffusion Policy，仅做 behavior cloning。Diffusion Policy 的
核心设定是：clean video / clean state 作为 observation condition，扩散变量仅为未来
action chunk；训练时对 GT action chunk 加噪，模型根据 clean observation、noisy action 和
diffusion timestep 预测噪声或 denoised action，推理时从 action noise 去噪得到 clean action
chunk。

本任务先从已下载的 H2R / HumanAndRobot 数据中建立可训练的 Diffusion Policy BC pipeline，
为后续比较 GT 视频、Ours 合成视频、Mitty 合成视频、Phantom / render 视频等下游 action
prediction 质量打基础。

## 目标

1. 在 FLIP 内新增 H2R Diffusion Policy BC 训练链路。
2. 从 H2R 数据中读取并对齐 robot video、robot state / proprioception 和 action label。
3. 训练一个 visuomotor Diffusion Policy：
   - condition：历史 clean video frames + 历史 clean state；
   - diffusion variable：未来 action chunk；
   - output：action noise prediction 或等价 denoising target；
   - inference result：clean future action chunk。
4. 完成最小训练、验证和 checkpoint save / load smoke。
5. 产出可复用的评估入口，后续能固定 policy 和 state/action label，仅替换 video observation
   来比较不同 H2R 外观编辑方法的下游 BC 效果。

## 范围

- 数据：优先使用已下载的 H2R / HumanAndRobot 数据集。
- 任务类型：offline behavior cloning，不接真机控制，不做仿真闭环。
- 模型：Diffusion Policy / action diffusion policy，不使用 DreamZero，不预测未来视频。
- 输入模态：
  - video history：机器人第一人称视频帧；
  - state history：机器人状态 / proprioception；
  - action chunk：未来动作序列，训练时加噪作为扩散变量。
- 评估主指标：
  - action chunk MSE；
  - per-horizon action MSE；
  - 可选 MAE / normalized MSE / relative error。
- 本任务只要求先在真实 H2R 视频上训练并验证 DP policy；合成视频对比可以实现基础接口，
  但完整 Ours / Mitty / Phantom / GT 对比表可作为后续任务扩展。
- 不保留旧 WAM / DreamZero 隐式 fallback；数据字段、维度、时间对齐或 checkpoint schema
  不合法时直接失败。

## 实施计划（分步骤）

1. 复核 H2R 数据落盘结构：
   - 确认视频路径、episode / trajectory id、frame rate、action rate；
   - 确认 state 和 action 字段名称、维度、单位和时间戳；
   - 明确 action 是 absolute、delta 还是 normalized command；
   - 记录可用 task / episode 数量和 train / val split 策略。
2. 设计 H2R Diffusion Policy dataset：
   - 按 `obs_horizon` 读取历史视频帧和 state；
   - 按 `pred_horizon` 读取未来 action chunk；
   - 支持 `action_horizon` / receding-horizon 执行长度配置；
   - 保存并复用 action / state normalization 统计；
   - 对缺帧、缺 action、长度不足样本直接报错或显式跳过并统计原因。
3. 新增或接入 Diffusion Policy 模型：
   - video encoder 可先采用轻量 CNN / ResNet / frozen visual encoder；
   - state encoder 使用 MLP；
   - action denoising backbone 可采用 1D temporal U-Net 或 transformer denoiser；
   - scheduler 支持 DDPM / DDIM 训练和采样参数；
   - checkpoint 保存完整 normalization、model config、scheduler config 和 action schema。
4. 新增训练入口：
   - 支持 batch size、obs horizon、pred horizon、diffusion steps、learning rate、AMP、
     workers、max samples、seed 等参数；
   - 支持小样本 smoke 和正式训练配置；
   - 输出 train / val denoising loss、sampled action MSE、per-horizon MSE。
5. 新增验证 / 评估入口：
   - 在 GT real video + GT state 上评估 action chunk prediction；
   - 支持固定 checkpoint 重放；
   - 导出逐样本预测、GT action、MSE、per-horizon MSE 和汇总 JSON / CSV；
   - 预留 `--video-override-root` 或等价接口，便于后续替换为 Ours / Mitty / Phantom
     合成视频。
6. 更新文档：
   - 在训练基础设施文档中记录 H2R DP 数据格式、训练命令、验证命令、checkpoint 字段；
   - 记录 Diffusion Policy 和 DreamZero / WAM 的边界区别；
   - 更新 `doc/scripts_inventory.md` 中新增入口说明。

## 验收标准

- 能从 H2R 数据构建 train / val dataset，并打印样本数、action/state 维度、horizon 配置和
  normalization 统计。
- 单 batch smoke 能输出：
  - video tensor shape；
  - state tensor shape；
  - noisy action tensor shape；
  - denoising prediction shape；
  - loss 标量。
- 训练入口能完成小样本训练并保存 checkpoint。
- checkpoint 能恢复后在同一 val subset 上执行验证，输出 sampled action chunk 和 GT action
  的 MSE。
- 验证结果包含 per-horizon MSE，便于观察短期 / 长期 action prediction 误差。
- 评估入口具备后续替换视频 observation 的接口，且默认真实视频路径下结果可复现。
- 文档明确说明本任务是 Diffusion Policy BC，不预测未来视频，不做 World Model。

## 测试要求

- `python -m compileall <新增或修改的 Python 文件>`
- 训练入口 `--help` smoke。
- 验证 / 评估入口 `--help` smoke。
- H2R dataset 单 batch shape smoke。
- 小样本训练 smoke：建议先限制 `--max-train-samples` / `--max-val-samples`，确认 loss 正常下降。
- checkpoint save / load smoke：恢复后跑同一 val subset，确认输出 schema 稳定。
- 如使用 GPU，优先通过 `scripts/flip_run.sh <subcommand>` 统一入口运行。

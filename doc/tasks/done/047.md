## 背景

现有离线评估主要覆盖 PSNR/SSIM/LPIPS/FID/FVD/Local FID/Patch FID 等视觉指标，缺少能够回应具身控制一致性的 action-aware 指标。评估视频已经保存成对的 `gen_*.mp4` / `gt_*.mp4`，并通过 `data_split/*.jsonl` 保留 `robot_task`、`episode`、`seg`、`clip_start`、`clip_dur` 等溯源字段。原始 LeRobot parquet 中包含 `action.ee_action` 和 `action.hand_cmd`，可作为双臂末端与双手控制监督信号。

## 目标

实现一个基于 Wan VAE latent 的轻量 arm-hand IDM：输入 robot 视频片段，输出 arm action 与 hand action，并把该模型用于离线评估生成视频的 action consistency。

## 范围

- 新增 action 标签解析逻辑：从 eval 记录或原始数据中按 `robot_task`、`episode`、`seg`、`clip_start`、`clip_dur` 对齐 `action.ee_action` 与 `action.hand_cmd`。
- 新增 Wan VAE 特征版 IDM 训练脚本：冻结 Wan VAE，训练小型 temporal regression head，输出 arm/hand 两组 action。
- 支持小规模 smoke 训练并打印/保存 train loss，确认 action loss 可下降。
- 新增离线评估入口或扩展现有指标入口：对 `gt` 与 `gen` 视频分别预测 action，并输出 arm/hand/combined MSE 与相对 GT 上限的 gap/ratio。
- 更新训练/评估文档，说明模型、标签、指标口径和运行命令。

## 实施计划（分步骤）

1. 阅读现有 Wan VAE cache/generation 调用路径，复用项目已配置的 VAE 路径、视频读写与环境约定。
2. 实现 action 标签 resolver，优先从原始 LeRobot parquet 读取 `action.ee_action` 与 `action.hand_cmd`，并按 eval 视频帧率映射到 clip 时间窗口。
3. 实现 Wan VAE latent extractor 与轻量 IDM 模型，确保 VAE 冻结，仅训练下游 action head。
4. 新增训练 CLI，支持限制样本数、batch size、device、checkpoint 输出和 loss 日志。
5. 新增 eval CLI 或集成到离线 summary，写出 `gt_idm_*`、`gen_idm_*`、`idm_*_gap`、`idm_*_ratio` 字段。
6. 运行 compile/smoke 测试，并在空闲 GPU 上跑小规模训练，检查 loss 是否下降。

## 验收标准

- 训练脚本可在少量 robot 片段上启动并完成若干 step，action loss 有下降趋势。
- 标签解析能从 `data_split/*.jsonl` 或 pair/eval 记录定位到真实 `action.ee_action` + `action.hand_cmd`。
- 评估结果表包含 arm、hand、combined 的 GT IDM error、gen IDM error、gap 和 ratio。
- 代码不依赖隐式 fallback；缺少必要数据、模型或对齐字段时直接报错。
- 相关文档已更新。

## 测试要求

- `python -m compileall` 覆盖新增/修改的 Python 模块。
- action resolver 小样本 smoke：确认输出维度、帧数和字段对齐。
- Wan VAE IDM 小规模训练 smoke：在空闲 GPU 上跑少量 step，记录首尾 loss。
- 如集成 summary，使用已有 eval 目录跑 `--max-samples` 或等价小样本评估 smoke。

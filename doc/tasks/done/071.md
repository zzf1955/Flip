## 执行计划

1. 在 `.worktrees/t070` 中运行 `robot_wam build-manifest`。
2. 用 `robot_wam inspect` 验证 manifest：
   - 样本数；
   - task 数；
   - raw HDF5 可以存在 `human_camera`，但 manifest/model IO 不引用 human video。
3. 运行 `robot_wam cache-t5`。
4. 运行 `robot_wam cache-vae`：
   - 使用 GPU；
   - 使用 CPU prefetch；
   - 支持 resume。
5. 运行 `robot_wam inspect --cache-dir` 验证 VAE cache schema。
6. 启动 `robot_wam train-wan`：
   - 主训练进程只加载 DiT；
   - 不加载 T5/VAE；
   - 使用 DataLoader prefetch；
   - checkpoint 保存 trainable-only LoRA + state/action 模块。

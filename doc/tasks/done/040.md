## 背景

当前 `src.pipeline.evaluate_mitty_models` 离线评估会在 in-task 和 OOD split 上生成 `gen_*.mp4`，复制 `gt_*.mp4` / `ctrl_*.mp4`，再用整视频计算 PSNR、SSIM、LPIPS、FID 和 FVD。

`blur_r2r` 数据生成时依赖 `training_data/sam2_mask/<task>/<episode>/<seg>.npz`，mask 表示机器人区域。现在需要在同一套 in-task/OOD eval 样本上，额外按该 mask 把视频拆成前景和背景，并分别计算拆分后视频的 FID/FVD。

## 目标

- 在离线综合评估中支持读取 `blur_r2r` 的 SAM2 mask，默认由 `--mask-region-metrics auto` 控制。
- 按每个 eval 样本的 `episode`、`seg`、`clip_start`、`clip_dur`、`augment` 对齐 mask 与输出视频帧。
- 为 `gen` 和 `gt` 分别生成前景视频/背景视频视图，并计算 foreground/background 的 FID 与 FVD。
- 新增全局 MSE，以及只统计 mask 内/外像素的局部 MSE、PSNR、SSIM。
- 区域 FID/FVD 明确使用黑底视频口径，字段名体现 black-background。
- 指标同时覆盖 `in_task_eval` 和 `ood_eval`。

## 范围

- 修改 `src.tools.eval_metrics`，支持可选 mask 加载与区域 FID/FVD。
- 修改 `src.pipeline.evaluate_mitty_models`，将选中样本记录传给指标计算，并提供 mask root 开关。
- 更新 `doc/step_5_training_infra.md` 与 `doc/requirement-log.md`。

## 实施计划

1. 抽取 mask 对齐逻辑，复用 `make_pair.py` 中的 clip frame 到 segment mask frame 映射口径。
2. 对每个 `gen/gt` pair 构建 binary foreground/background 视频数组；前景只保留 mask 内像素，背景只保留 mask 外像素。
3. 在原有整视频 FID/FVD 之外追加 `foreground_black_fid`、`foreground_black_fvd`、`background_black_fid`、`background_black_fvd`。
4. 在配对指标中追加 `mse`、`foreground_mse`、`foreground_psnr`、`foreground_ssim`、`background_mse`、`background_psnr`、`background_ssim`。
5. 离线评估 summary CSV/JSON 写出新增字段；缺少 mask 时直接报错，不回退到整视频。

## 验收标准

- `blur_r2r` eval 样本能从 manifest/cache record 反查到 SAM2 mask。
- `--no-generate` 复算已有输出时也能使用 `data_split/*.jsonl` 计算区域 FID/FVD。
- in-task 和 OOD summary 都包含 foreground/background 黑底 FID/FVD 字段。
- in-task 和 OOD summary 都包含全局 MSE 与 mask 局部 MSE/PSNR/SSIM 字段。
- 非 `blur_r2r` 默认不启用 mask 区域指标；显式启用但缺 mask 时失败。
- `--no-fid` 只关闭 Frechet 指标，不关闭 mask 局部 MSE/PSNR/SSIM。

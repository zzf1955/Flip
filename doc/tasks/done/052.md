## 背景

task 051 的两帧 IDM 使用 `(s_t, s_{t+1}) -> action[t]` 单点动作监督。后续
offset sweep 显示 `action[t+k]` 的最优 offset 不稳定，且不同 offset 之间差距较小；
这说明单帧 action 标签可能受控制延迟、动作噪声和视频低帧间变化影响，难以稳定解释
两帧视觉差异。

更合理的 inverse dynamics 口径是让模型观察一个状态区间的起止帧，并预测该区间内
实际执行动作的平均值：

```text
输入: (s_t, s_{t+d})
输出: mean(action[t : t+d])
```

其中 `d` 是帧间隔，`action[t : t+d]` 为半开区间，包含 `t`，不包含 `t+d`。

## 目标

1. 在 H1 Humanoid pair IDM 中新增区间动作预测能力，支持 `(frame_t, frame_{t+d})`
   输入和 `mean(action[t:t+d])` 标签。
2. 保留 task 051 的相邻帧单点预测能力，不直接删除旧口径。
3. 用 `frame_delta` sweep 比较 `d=1/2/4/8/16` 的效果，判断 interval mean action
   是否比单点 action 更稳定。
4. 复用 task 051 新增的 normalized MSE、R2、correlation、预测方差比等诊断指标。
5. 如果 H1 实验证明有效，再评估是否将同一能力扩展到 WBT `wan_pair_idm` 的 arm/hand
   双网络路径。

## 范围

- 第一阶段只要求实现和验证 `src.pipeline.humanoid_pair_idm` 的 interval mean action。
- 输入帧为 `frame_t` 和 `frame_{t+d}`，仍拼成 6 通道 RGB 输入小 CNN。
- 标签固定为半开区间 `mean(action[t:t+d])`，不在本任务中引入额外 action offset。
- `frame_stride` 仍表示采样候选起点的步长；新增 `frame_delta` 表示两帧间隔和动作平均窗口。
- split 必须保持 episode-level train/eval 不重叠；显式 train/eval sample count 也不能破坏
  episode 隔离。
- 需要同步更新 `doc/step_5_training_infra.md`、`doc/scripts_inventory.md` 和
  `doc/requirement-log.md`。

## 实施计划（分步骤）

1. 为 `humanoid_pair_idm` 增加 `--frame-delta` 参数，默认 `1`，并清楚区分
   `frame_stride` 与 `frame_delta`。
2. 修改样本发现逻辑：只保留满足 `t + frame_delta < episode_len` 且区间内不跨
   `next.done` 的样本。
3. 修改数据读取：输入读取 `frame_t` 与 `frame_{t+frame_delta}`，而不是固定
   `frame_t` 与 `frame_{t+1}`。
4. 修改标签构造：`action_target = mean(action[t:t+frame_delta])`，保存到 sample
   metadata，checkpoint config 记录 `frame_delta` 和 target 语义。
5. 增加 sweep 友好的训练/验证命令示例，至少覆盖 `frame_delta=1,2,4,8,16`。
6. 在 H1 子集上跑轻量 sweep，记录 raw MSE、normalized MSE、R2、correlation、
   pred/target std ratio，并和原单点口径对照。
7. 若 `frame_delta > 1` 明显优于 `1`，补充正式推荐配置；若没有明显改善，记录结论并
   保持旧口径作为默认可用 baseline。

## 验收标准

- `humanoid_pair_idm train/validate/eval` 都支持 `--frame-delta`，且 checkpoint 复算会
  默认复用训练时的 `frame_delta`。
- `frame_delta=1` 能复现旧的相邻帧输入，但标签为 `mean(action[t:t+1])`，等价于
  `action[t]`。
- `frame_delta>1` 时输入确实为 `frame_t` 与 `frame_{t+d}`，标签确实为
  `mean(action[t:t+d])`。
- train/eval episode 无重叠，显式 `--train-samples` / `--eval-samples` 不引入同
  episode 泄漏。
- 输出指标包含 raw MSE、mean baseline、normalized MSE、R2、correlation、预测方差比。
- 文档清楚说明 `frame_stride`、`frame_delta` 和 interval mean action 的语义。

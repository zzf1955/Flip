## 背景

task054 已复现 AdaWorld action encoder，task056 已完成 AdaWorld latent action decoder
的代码落地与小样本 smoke。当前需要把这个基于 AdaWorld 的 IDM 真正跑到
Humanoid Everyday H1 的完整 1600 条数据上，形成正式训练结果和可复算指标，而不是只
停留在小样本验证。

这里的“1600 条 H1 数据”指 `data/humanoid-everyday-h1-chunks0-6-8-200` 这套完整
Humanoid Everyday H1 LeRobot 数据根。task057 不再做 encoder 复现，只做：

`(frame_t, frame_{t+1}) -> AdaWorld z_t -> action_t`

的全量训练、验证和评估。

## 目标

1. 基于 task056 的 `src.pipeline.adaworld_action_decoder`，在完整 H1 数据根上跑全量训练。
2. 如需要，先用 task054 的 AdaWorld action encoder 对完整 H1 数据提取 latent artifact，
   再喂给 decoder 训练。
3. 用完整 1600 条 H1 数据跑通 train / validate / eval 闭环，生成正式 checkpoint 和指标。
4. 对比 mean baseline 和现有两帧 RGB IDM，记录 AdaWorld latent decoder 的实际收益。
5. 将全量训练配置、数据量、指标和局限写回文档。

## 范围

- 只做 H1 全量训练，不扩展到 WBT 或其他任务。
- 不重新训练 AdaWorld action encoder。
- 不加载 AdaWorld world model。
- 默认沿用 task056 的 MLP decoder baseline，不在本任务里引入新的架构搜索，除非全量
  训练证明需要调参才能稳定收敛。
- 不做隐式 fallback；数据缺失、latent artifact 缺失或 schema 不符时直接失败。

## 实施计划

1. 在完整 H1 数据根上生成 AdaWorld latent artifact，或复用已有完整 artifact。
2. 使用 task056 的 decoder 入口在全量样本上训练，优先按 episode split，保证 train/eval
   不重叠。
3. 跑完整 validate / eval，保存 `best_checkpoint.pt`、`metrics.json`、
   `val_predictions.csv` 和 `loss_curve.png`。
4. 如果全量训练中发现明显的过拟合或均值回归，再调整 decoder 宽度、深度、学习率或
   正则，而不是改回图像端端到端 baseline。
5. 更新任务文档和训练文档，记录正式全量结果。

## 验收标准

- 在 `data/humanoid-everyday-h1-chunks0-6-8-200` 上完成一次可复算的全量训练。
- 训练结果包含 checkpoint、loss 曲线、验证预测表和评估指标。
- `validate` / `eval` 能基于 checkpoint 复算，且指标与训练时一致。
- 文档写清楚全量数据规模、latent 生成方式、decoder 配置和与 baseline 的对比结果。

### Decoder 全量训练

训练命令：

```bash
scripts/flip_run.sh adaworld_action_decoder --cuda 1 -- train \
  --device cuda:0 \
  --data-root /disk_n/zzf/flip/data/humanoid-everyday-h1-chunks0-6-8-200 \
  --latent-path /disk_n/zzf/flip/.worktrees/t057/tmp/adaworld_action_encoder_h1_full_t057/latent_actions.npz \
  --output-dir tmp/adaworld_action_decoder_h1_full_t057 \
  --split-by episode \
  --steps 2000 \
  --batch-size 1024 \
  --eval-every 500 \
  --log-every 100 \
  --workers 0
```

- 模型：默认 MLP decoder，`32 -> 128 -> 128 -> 26`，LayerNorm enabled。

- split：episode-level，train/val episode 不重叠。
- 输出目录：`tmp/adaworld_action_decoder_h1_full_t057`

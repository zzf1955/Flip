## 背景

task054 已复现 AdaWorld LAM action encoder，task056 已实现 AdaWorld latent action
decoder IDM，task057 已在完整 Humanoid Everyday H1 1600 episode 数据上完成全量
训练与复算。当前 AdaWorld IDM 数据流为：

`(frame_t, frame_{t+1}) -> AdaWorld z_t[32] -> action_t[26]`

现有全量结果使用 `src.pipeline.adaworld_action_decoder` 的默认小 MLP decoder：

- 架构：`32 -> 128 -> 128 -> 26`，启用 LayerNorm，dropout 为 `0.0`。
- 优化：AdamW，`lr=1e-3`，`weight_decay=1e-4`，cosine scheduler，
  `min_lr_ratio=0.05`。
- 数据：`data/humanoid-everyday-h1-chunks0-6-8-200`，`560422` 个 latent/action
  样本，episode-level split。
- task057 held-out best checkpoint：
  - `action_mse = 0.07853357493877411`
  - `mean_baseline_action_mse = 0.15635326504707336`
  - `action_mean_dim_r2 = 0.504274274294193`
  - `action_mean_dim_corr = 0.7063991037698892`
  - `action_pred_std_ratio_mean = 0.7120954027542701`
- task057 全量 eval：
  - `action_mse = 0.07298979163169861`
  - `mean_baseline_action_mse = 0.15620023012161255`
  - `action_mean_dim_r2 = 0.5340813008638529`
  - `action_mean_dim_corr = 0.7275451834385211`
  - `action_pred_std_ratio_mean = 0.7190383053742923`

当前结果已经显著优于 mean baseline，但 decoder 仍是很保守的基础 MLP，训练步数和学习率
也只做了一轮默认配置。下一步应在不改变 AdaWorld latent 提取口径和监督语义的前提下，
系统调整学习率、scheduler、网络宽度/深度、归一化、dropout、残差结构等基础参数，尝试
继续降低 held-out 预测误差，并检查是否存在逐维输出方差不足或高误差维度拖累的问题。

## 目标

1. 在 task057 的完整 H1 AdaWorld latent artifact 和 episode-level split 口径上，建立
   可复算的 decoder 优化基线。
2. 系统探索学习率、min lr、warmup/scheduler、weight decay、batch size、grad clip 等
   基础训练超参对 held-out action MSE 和 normalized 指标的影响。
3. 探索轻量 decoder 架构变体，例如更宽/更深 MLP、residual MLP、不同归一化位置、
   gated/FiLM 风格 MLP 或 per-dim/group head，优先控制参数量和复算成本。
4. 对比新配置与 task057 默认配置，重点看 `action_mse`、normalized RMSE、逐维 R2 /
   correlation、预测方差比和高误差维度。
5. 形成推荐默认配置，并把可复现命令、指标表、失败配置和使用边界写回文档。

## 范围

- 只优化 AdaWorld latent action decoder IDM，即 `src.pipeline.adaworld_action_decoder`
  及其对应文档。
- 默认复用 task057 已生成的全量 latent artifact，不重新跑 AdaWorld action encoder，除非
  artifact 缺失或需要验证 latent 一致性。
- 不加载、不训练 AdaWorld world model。
- 不改变当前监督语义：仍是 `(frame_t, frame_{t+1}) -> z_t -> action_t`，不切换到
  interval mean 或多帧 target。
- 不把本任务扩展到 H1 RGB Transformer IDM；该方向已由 task060 覆盖。
- 不做静默 fallback；checkpoint config、latent artifact、split 或 action schema 不合法时
  直接失败。

## 实施计划（分步骤）

1. 审计 task057 产物和 `best_val_predictions.csv` / `metrics.json`，整理当前高误差维度、
   低 correlation 维度、预测方差不足维度，以及 train/eval loss 是否仍有优化空间。
2. 为 `adaworld_action_decoder` 增加必要的超参或架构开关，确保 checkpoint 保存完整配置，
   `validate` / `eval` 可以严格复算。
3. 先做低成本 sweep，覆盖学习率、scheduler/min lr、weight decay、batch size、hidden dim、
   depth、dropout、LayerNorm 开关等基础参数。
4. 在低成本 sweep 中筛出 2-3 个候选，再用完整 held-out split 训练到与 task057 可比的步数
   或更长步数，记录收敛曲线和 best checkpoint。
5. 如基础 MLP 宽深调整收益有限，再实现一个残差 MLP 或 gated MLP 变体，并与默认 MLP
   同 split 对照。
6. 对最佳候选运行 `validate` 和全量 `eval` 复算，保存预测表、metrics、loss curve 和
   推荐训练命令。
7. 更新 `doc/step_5_training_infra.md`、`doc/scripts_inventory.md` 和
   `doc/requirement-log.md`，记录最佳配置、相对 task057 的误差变化、失败配置和后续建议。

## 验收标准

- 至少完成一组与 task057 同数据、同 episode-level split、同 latent artifact 的可复算对照。
- 新配置的 held-out `action_mse` 相比 task057 的 `0.07853357493877411` 有明确改善，或在
  指标未改善时给出基于 sweep 的原因分析。
- 逐维诊断中至少说明哪些 action 维度改善、哪些维度仍受限，以及预测方差比是否更接近
  target 分布。
- 最佳 checkpoint 可通过 `validate` 复算，且全量 `eval` 输出完整 `metrics.json` 和
  `predictions.csv`。
- 文档中明确推荐默认超参/架构、复现实验命令、输出目录和与 task057 baseline 的差异。

### 主要变更

- `src.pipeline.adaworld_action_decoder` 新增 `--decoder-arch {mlp,residual_mlp,gated_mlp}`。
- `residual_mlp` 使用 hidden projection、pre-norm residual MLP blocks 和两层输出 head；
  `gated_mlp` 在 residual block 内使用 gated activation，供后续消融。
- 训练新增 AdamW `--adam-beta1/--adam-beta2`、`--lr-warmup-steps`、
  `--lr-warmup-ratio`，scheduler 支持 warmup + cosine / warmup + flat。
- checkpoint 保存完整 decoder 架构、优化器、scheduler 和 warmup 配置，`validate` /
  `eval` 可严格 replay。
- 更新 `doc/step_5_training_infra.md`、`doc/scripts_inventory.md` 和
  `doc/requirement-log.md`，记录推荐配置、复现命令和 task057/task061 指标对比。

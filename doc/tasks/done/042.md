## 背景

离线 `evaluate_mitty_models` 当前主要通过 `--eval-tail-percent` 从各 task 的
`pair_order.jsonl` 尾部按百分比选样本。新的评估需求希望直接输入 in-task 和
OOD 的样本数量：in-task 按各 task 数据量比例分配后从每个顺序表尾部读取，OOD
当前只有一个 task，从该 OOD 顺序表尾部读取指定数量。

同时，Local FID 的 bbox crop 应输出可视化视频和索引表，便于把局部 patch/crop
对应回 pair 数据的 `order_index`、`pair_id` 和 `source_id`。

## 目标

- `evaluate_mitty_models` 支持按 `--in-task-eval-size` 和 `--ood-eval-size`
  进行 count-based eval selection。
- 保留 `--eval-tail-percent` 作为兼容路径；新 count 参数优先用于正式评估。
- 输出 Local crop 视频和 `patch_index.jsonl`，显式记录 sample、pair order、
  mask 和 bbox 对应关系。

## 范围

- 修改 `src/pipeline/runtime_data.py` 的离线 eval 选择逻辑。
- 修改 `src/pipeline/evaluate_mitty_models.py` 的 CLI、选择调用和 Local 视频输出。
- 复用 `src/tools/eval_metrics.py` 中 Local FID mask/bbox helper。
- 更新 `doc/step_5_training_infra.md` 和需求日志。
- 不实现 ROI-FVD。

## 实施计划（分步骤）

1. 增加 count-based tail eval split builder，in-task 总数按 task 容量比例分配，
   OOD 总数按 OOD task 容量比例分配并支持单 OOD task。
2. 为 `evaluate_mitty_models` 增加 `--in-task-eval-size`、`--ood-eval-size`、
   `--write-local-videos`、`--local-video-margin`、`--local-video-size` 等参数。
3. 使用 SAM2 mask 对齐结果生成 Local crop 视频，输出到 `<split>/local_fid/`。
4. 写出 `<split>/local_fid/patch_index.jsonl`，每条记录包含 `sample_id`、
   `robot_task`、`pair_id`、`order_index`、`pair_order_path`、`source_id`、
   `mask_path` 和 bbox 信息。
5. 更新文档和需求日志。
6. 运行语法检查和不加载模型的选择/Local 视频 smoke。

## 验收标准

- 传入 `--in-task-eval-size K --ood-eval-size M` 时，summary 的 `n_samples`
  与选择数量一致。
- `data_split/*.jsonl` 中保留可反查 pair 数据的 `order_index` 和
  `pair_order_path`。
- `--write-local-videos` 会输出 Local crop 视频和 `patch_index.jsonl`。
- Local crop 使用与 Local FID 一致的 SAM2 mask 对齐和 bbox 扩展逻辑。
- 缺失 mask 或索引字段时直接报错。

## 测试要求

- 验证 `patch_index.jsonl` 能对应回 selected records 的 `order_index`。

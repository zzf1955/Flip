## 背景

task051 / task052 已经实现了两帧 RGB IDM：直接从 `(frame_t, frame_{t+1})`
监督预测真实 action。H1 实验显示该路线只略优于 mean baseline，说明直接从少量有标签
视频端到端回归 action 的效果不足。

新的目标是只复现 AdaWorld 的 action encoder 部分：输入两帧图像
`(f_t, f_{t+1})`，输出 32 维连续 latent action。AdaWorld 后续的 world model /
视频预测部分本任务先不做。

参考仓库按用户约定 clone 到 `ref-<repo_name>`，对
`https://huggingface.co/Little-Podi/AdaWorld` 应使用 `ref-AdaWorld`。之前曾存在的
`ref-xxx/` 已被删除，不作为本任务参考或约束。

## 目标

1. clone AdaWorld 参考仓库到 `ref-AdaWorld`，只分析 action encoder 相关代码路径。
2. 在 FLIP 中接入或复现 AdaWorld action encoder，使其接受 H1 两帧 RGB 图像输入。
3. 输出 32 维连续 latent action `z_t`，时序口径固定为 `(frame_t, frame_{t+1}) -> z_t`。
4. 提供最小可运行 CLI：从 H1 LeRobot 视频读取两帧，前向 action encoder，并保存 latent
   action artifact。
5. 保持旧 `wan_pair_idm`、`humanoid_pair_idm` 不被替换；本任务只新增独立入口和文档。

## 范围

- 本任务只覆盖 AdaWorld 的 action encoder，不实现、不训练、不调用后续 world model。
- 本任务必须跑通的是 inference / extract 口径：H1 两帧图像输入，输出 32 维连续 latent
  action；是否训练 action encoder 取决于 AdaWorld 是否提供可直接加载的权重和配置。
- 数据优先复用现有 Humanoid Everyday H1 LeRobot 数据：
  `data/humanoid-everyday-h1-chunks0-6-8-200`；如需过滤坏 parquet，应复用 task052
  的有效数据根处理经验。
- action encoder 输入只使用 egocentric RGB 视频，不读取 proprioception 或真实 action。
- 输出 latent action 固定为 32 维连续向量，不在本任务中映射到 H1 26 维真实 action。
- 新实现应保存 latent action artifact，便于后续任务再训练 action head。
- 不做宽泛 fallback 到旧 IDM；缺失视频、action、checkpoint 或 latent artifact 时直接报错。

## 实施计划（分步骤）

1. clone `https://huggingface.co/Little-Podi/AdaWorld` 到 `ref-AdaWorld`，记录 commit /
   revision，并定位 action encoder 的模型定义、配置、权重加载和图像预处理。
2. 设计 FLIP 版 H1 两帧读取器：从 LeRobot parquet 和 mp4 生成
   `(frame_t, frame_{t+1})` 样本，并复用现有 episode-level split / 坏 parquet 处理经验。
3. 新增独立入口，例如 `src.pipeline.adaworld_action_encoder`，只暴露 action encoder 相关能力：
   - 加载 AdaWorld action encoder 配置和 checkpoint。
   - 对 H1 两帧图像执行与 AdaWorld 一致的 resize / normalize / tensor layout。
   - 输出 32 维连续 latent action。
4. 新增 extract 子命令：对指定 H1 episode / 样本数逐步输出 `z_t`，保存为 `.npz` /
   `.jsonl` / manifest，记录源 episode、frame index、frame delta、模型 revision 和预处理配置。
5. 在 H1 小样本上跑 smoke：读取两帧、前向 action encoder、确认 latent shape 为
   `[N, 32]`、数值 finite，并可复算同一 checkpoint / 输入得到一致输出。
6. 更新 `scripts/flip_run.sh`、`doc/scripts_inventory.md`、
   `doc/step_5_training_infra.md` 和 `doc/requirement-log.md`。

## 验收标准

- `ref-AdaWorld` 存在并指向 AdaWorld 参考仓库；任务记录使用的 revision。
- 有独立 CLI 可以从 H1 两帧 RGB 图像输出 32 维连续 latent action。
- latent action extractor 只依赖纯视觉输入，不读取真实 action label。
- artifact 足够完整，后续可以直接读取 `z_t` 训练 action head。
- 文档明确写清楚 latent action 的时序语义、artifact schema、extract 命令和当前局限。

## 测试要求

- `python -m compileall` 覆盖新增 pipeline 文件。
- `scripts/flip_run.sh <new-subcommand> --help` 可用。
- H1 小样本 smoke：
  - 从 H1 mp4 读取两帧。
  - action encoder 前向输出 `[N, 32]` latent action。
  - latent 数值 finite，不全为常数。
  - extract artifact 可被独立读取并校验 schema。
